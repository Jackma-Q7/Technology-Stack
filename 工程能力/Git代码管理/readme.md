不需要完全记住每个命令的详细使用方法，只需：
1.完全熟悉《5分钟掌握个人开发流程》
2.记住工作、暂存区、版本库、远程仓库的组成，提交和撤销到每个步骤
3.其余的有个概率，具体使用直接问AI即可。可以使用创建自己的技术栈来实践管理一个项目代码

## 9.3.1使用开源库驱动多路电机

电路中AIN1(I023)对应AOUT1，AIN2(IO 22)对应 AOUT2，DRV8833 会将 AIN1(IO23)和AIN2(IO 22)上的电信号放大到对应的输出引脚上，我们将电动机接在输出引脚即可。

**添加库**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/57223890/1765849304990-c25853ed-ffa2-40a0-aa37-5ee11a2f2132.png)

```cpp
#include <Arduino.h>
#include <Esp32McpwmMotor.h>

// 创建一个名为 motor 的对象，用于控制电动机
Esp32McpwmMotor motor;

void setup()
{
    // 绑定电机通道与控制引脚
    // 电机 0：PWM 引脚 22，方向引脚 23
    motor.attachMotor(0, 22, 23);

    // 电机 1：PWM 引脚 12，方向引脚 13
    motor.attachMotor(1, 12, 13);
}

void loop()
{
    // 正转：占空比 70%
    motor.updateMotorSpeed(0, 70);   // 电机 0 正转
    motor.updateMotorSpeed(1, 70);   // 电机 1 正转
    delay(2000);                     // 延时 2 秒

    // 反转：占空比 70%
    motor.updateMotorSpeed(0, -70);  // 电机 0 反转
    motor.updateMotorSpeed(1, -70);  // 电机 1 反转
    delay(2000);                     // 延时 2 秒
}
```

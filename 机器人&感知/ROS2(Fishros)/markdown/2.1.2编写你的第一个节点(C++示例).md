## 2.1.2编写你的第一个节点( C++ 示例)
### 代码
```cpp
#include "rclcpp/rclcpp.hpp"

int main(int argc,char **argv)
{
    rclcpp::init(argc,argv)
    auto node = std::make_shared<rclcpp::Node>("cpp_node");
    RCLCPP_INFO(node->get_logger()，"你好 C++ 节点!");
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}
```
这两个参数是命令行参数：
`int argc`

表示参数个数，英文是 argument count。

`char **argv`

表示参数内容，英文是 argument vector。它本质上可以理解为“字符串数组”。

例如你在终端运行：

`./demo hello 123`

那么：

`argc = 3`

因为一共有 3 个参数：
```
argv[0] = "./demo"
argv[1] = "hello"
argv[2] = "123"
```
注意：argv[0] 一般是程序自己的名字或路径。

`char **argv` 也经常写成：

```
char *argv[]
argv 是一个数组；
数组里的每个元素都是 char*；
所以它是“指针数组”。
```

这两个在函数参数里基本等价：

`int main(int argc, char *argv[])`

更好理解一些：argv 是一个数组，数组里的每个元素都是 char* 字符串。

### 完整CMakeLists.txt
```cmake
cmake_minimum_required (VERSION 3.8)
project(ros2_cpp)
add_executable(ros2_cpp_node ros2_cpp_node.cpp)
#查找rclcpp头文件和库文件的路径
find package(rcIcpp REQUIRED)

message(STATUS ${rcLCPP INCLUDE DIRS})# 头文件及rclcpp依赖的头文件
message(STATUS ${rcLcPP LIBRARIES})#库文件及rclcpp依赖的库文件

# 给可执行文件包含头文件
target_include_directories(ros2_cpp_node PUBLIC ${rcIcpp_INCLUDE_DIRS})
# 给可执行文件链接库文件
target_link_libraries(ros2_cpp_node ${rcIcpp_LIBRARIES})
```

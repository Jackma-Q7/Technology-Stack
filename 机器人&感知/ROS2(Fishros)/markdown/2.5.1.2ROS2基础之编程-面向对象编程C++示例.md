## 2.5.1ROS2基础之编程:面向对象编程C++示例
```cpp
#include <string>
#include "rclcpp/rclcpp.hpp"

class PersonNode:public rclcpp::Node
{
private :
    std::string name_;
    int age_ ;

public:
    PersonNode(const std::string &node_name,
        const std::string &name,
        const int &age)
        :Node(node_name)//调用父类的构造函数
    {
    this->name_ = name;
    this->age_ =age;
    };

    void eat(const std::string &food_name)
    {
        RCLCPP_INFO(this->getlogger(),"我是 %s，今年 %d岁，我现在正在吃号 %s",
            name_.c_str(),age_,food_name.c_str());
    }

int main(int argc,char **argv)
{
    rclcpp::init(argc,argv);
    auto node = std::make_shared<PersonNode>("cpp_node","法外狂徒张三",18);
    node->eat("鱼香ROS");
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}
```

`Node(node_name)` 可以理解成一句话：

先把父类 rclcpp::Node 这部分创建出来，并且给它起名叫 node_name。

你的类是：
```cpp
class PersonNode : public rclcpp::Node
```
说明 `PersonNode` 继承了 `rclcpp::Node`。

所以一个 `PersonNode` 对象里面，其实包含两部分：
```
PersonNode 对象
├── 父类 rclcpp::Node 部分
└── 子类 PersonNode 自己的部分
    ├── name_
    └── age_
```
这句：
```cpp
: Node(node_name)
```
就是在初始化这个父类部分：
```
父类 rclcpp::Node 部分的名字 = node_name
```
例如你写：
```cpp
auto node = std::make_shared<PersonNode>("cpp_node", "张三", 18);
```
那么构造时：
```cpp
node_name = "cpp_node"
```
所以：
```cpp
: Node(node_name)
```
实际等价于：
```cpp
: rclcpp::Node("cpp_node")
```
也就是告诉 ROS 2：

创建一个 ROS 2 节点，节点名叫 cpp_node

注意它不是调用你自己的 PersonNode，而是在调用父类 rclcpp::Node 的构造函数。

可以类比：
```cpp
class Animal
{
public:
    Animal(std::string type)
    {
        // 创建动物类型
    }
};

class Person : public Animal
{
public:
    Person(std::string type, std::string name)
        : Animal(type)   // 先构造父类 Animal
    {
        // 再构造 Person 自己
    }
};
```
你的代码里：
```cpp
: Node(node_name)
```
就相当于：
```cpp
: Animal(type)
```
一句话：

`: Node(node_name)`就是 调用父类 rclcpp::Node 的构造函数，把当前对象注册成一个 ROS 2 节点，并设置节点名。

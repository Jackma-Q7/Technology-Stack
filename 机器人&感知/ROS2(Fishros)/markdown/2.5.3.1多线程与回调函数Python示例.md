## 2.5.3.1多线程与回调函数Python示例
### 多线程与回调函数
单线程:
```
线程1下载(第一章)

线程1 统计字数(第一章内容)

线程1下载(第二章)

线程1 统计字数(第二章内容)

线程1下载(第三章)

线程1 统计字数(第三章内容)
```
多线程:
```
线程1 下载第一章()          线程2 下载第二章()             线程3 下载第三章()
```
问题:下载完成怎么统计字数?

1.再开个线程4，不断依次询问是否下载完成，下载完就获取内容统计(低效浪费)

2.把统计函数当作参数传递给下载函数，下载完自己第一时间调用(高效节省资源)

方案2中的 统计函数 就是回调函数，回调回调，回头再调!

```python
import threading
import requests

class Download:
    def download(self, url, callback):	
        print(f'线程:{threading.get_ident()}开始下载:{url}')
        response = requests.get(url)
        response.encoding = 'utf-8'
        callback(url, response.text)
        
    def start_download(self, url, callback):
        thread = threading.Thread(target=self.download, args=(url, callback))
        thread.start()

    def download_finish_callback(self, url, result):
        print(f'{url} 下载完成，共:{len(result)}字，内容为:{result[:5]}...')

def main():
    d = Download()
    d.start_download('http://localhost:8000/novel1.txt', d.download_finish_callback)
    d.start_download('http://localhost:8000/novel2.txt', d.download_finish_callback)
    d.start_download('http://localhost:8000/novel3.txt', d.download_finish_callback)

if __name__ == "__main__":
    main()
```

## 4.5.1参数声明与设置
在 src/demo_cpp_service/src/turtle_control.cpp文件中添加代码

```cpp
class TurtleController : public rclcpp::Node {
public:
    TurtleController() : Node("turtle_controller") {
        // 声明和获取参数初始值
        this->declare_parameter("k", 1.0);
        this->declare_parameter("max_speed", 1.0);
        this->get_parameter("k", k_);
        this->get_parameter("max_speed", max_speed_);
    }

    ...
};
```

✅ **参数虽然被外部修改成功了，但节点内部变量不会自动更新**

书中的原文说：

参数的值已经被重新设置了，但此时节点中属性 k_ 的值并没有被更新，要实现动态更新，还需要订阅参数更新事件。

意思是：

+ 当你执行 `ros2 param set turtle_controller k 2.0` 时  
**ROS 2 参数服务器确实把参数 k 的值改成 2.0 了**

但是！

+ 你的节点内部变量：

```plain
double k_;
```

仍然保持为旧值（例如 1.0），**不会自动变成 2.0**。

---

❗ 为什么变量不会自动更新？

因为：

```plain
this->get_parameter("k", k_);
```

只会在构造函数里 **读取一次参数**。

之后无论外部怎么修改参数，`k_` 都不会再自动更新。

---

💡 怎样才能让 k_ 跟着参数变化？

需要为节点注册一个参数修改回调：

```plain
this->add_on_set_parameters_callback(
    std::bind(&TurtleController::param_callback, this, _1)
);
```

然后在回调中写：

```plain
if (param.get_name() == "k") {
    k_ = param.as_double();
}
```

这样，参数更新 → 节点内部变量也更新。

---

⭐ 用一句话总结

**“参数被外部成功修改 ≠ 节点内部变量自动更新。”**  
要想让节点内部使用的新参数生效，必须通过回调机制手动同步。

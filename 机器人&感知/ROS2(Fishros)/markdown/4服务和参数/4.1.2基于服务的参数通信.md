## 4.1.2基于服务的参数通信
在ROS2中，参数被视为节点的设置，而参数通信机制是基于服务通信实现的。

**查看指定节点的参数描述**

ros2 param describe /turtlesim background_r

**获取节点参数值**

ros2 param get /turtlesim background_r

**修改节点参数值**

ros2 param set /turtlesim background_r

**参数导出到文件**

ros2 param dump /turtlesim > turtlesim_param.yaml

**运行节点时指定参数文件**

ros2 run turtlesim turtlesim_node --ros-args --params-file turtlesim_param.yaml

在 rqt 工具中，插件 Configuration→ DynamicReconfgure 提供了一个可视化的参数配置工具，你可以运行rqt 自行尝试。

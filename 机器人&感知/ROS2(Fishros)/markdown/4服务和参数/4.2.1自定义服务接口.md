## 4.2.1自定义服务接口
需求:创建一个人脸检测服务，提供图像，返回人脸数量置信息

难点分析:

1.人脸怎么识别?face_recognition

2.图片数据和结果怎么传递?服务通信就很合适

3.没有合适的消息接口?自定义一个

ros2 pkg create chapt4_interfaces--build-type

ament_cmake

--dependencies

rosidl_default_generators 

sensor_msgs --license pache-2.0

**src/chapt4_interfaces/srv**

上面时请求，下面是返回

```cmake
# 查找依赖
find_package(ament_cmake REQUIRED)  # ROS 2的基础构建工具
find_package(rosidl_default_generators REQUIRED)  # ROS 2接口（msg/srv）生成工具
find_package(sensor_msgs REQUIRED)  # 依赖的消息包（包含传感器相关消息）

rosidl_generate_interfaces(${PROJECT_NAME}
  "srv/FaceDetector.srv"  # 自定义的服务文件（路径：功能包下的srv/FaceDetector.srv）
  DEPENDENCIES sensor_msgs  # 该服务依赖的消息包
)
```

除了修改CMakeLists.txt外，还需要修改功能包清单文件package.xml，添加<memberof_group>rosidl interface_packages</member_of_group>，

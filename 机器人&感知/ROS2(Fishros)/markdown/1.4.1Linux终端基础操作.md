## 1.4.1 Linux终端基础操作
### Linux终端基础操作~目录

```bash
pwd # 查看终端当前目录默认主目录

ls # 查看当前目录下的文件

cd/ # 从当前进入到根目录

cd~ # 查看主目录内
```

### Linux终端基础操作~文件

```bash
mkdir chapt1 # 在主目录下创建 chapt1 文件夹

touch hello world.txt #创建空白文件

nano hello_world.txt

cat hello world.txt

rm hello_world.txt
```

## 2.1.1编写你的第一个节点(Python示例)
```python
import rclpy
from rclpy.node import Node

def mian():
    rclpy.init()
    node = Node("python_node")
    node.get_logger().info('hello mjj')
    rclpy.spin(node)
    rclpy.shutdown()

if __name__=="__mian__":
    mian()
```

```
python3 ros2_python_node.py

ros2 node list

export RCUTILS_CONSOLE_OUTPUT_FORMAT=[{function_name}:{line_number}]:{message}
```

这条命令是 设置 ROS 2 日志输出格式 的。

它的作用是：让终端打印日志时，只显示：

[函数名:行号]:日志内容

例如原来 ROS 2 日志可能是：

`[INFO] [1710000000.123456789] [my_node]: hello world`

设置后可能变成：

`[main:25]:hello world`

## 3.3.1发布速度控制海龟画圆
需求:控制海龟模拟器中的小海龟转指定半径的圆

核心问题:

1.小海龟凭什么听我的?话题

2.前进后退我知道，画圆?线速度/角速度=半径3.发一下就停了，如何循环发?定时器
```
ros2 pkg create demo_cpp_topic --build-type ament cmake --dependencies rclcpp geometry_msgs turtlesim --license Apache-2.0
```
```cpp
#include "rclcpp/rclcpp.hpp"                 // ROS2 C++ 客户端库
#include "geometry_msgs/msg/twist.hpp"       // 速度消息类型 Twist
#include <chrono>                            // 使用 chrono 进行时间处理

// 使用 chrono 的字面量（比如 1000ms）
using namespace std::chrono_literals;

// 定义一个节点类 TurtleCircle，继承自 rclcpp::Node
class TurtleCircle : public rclcpp::Node
{
private:
    // 定时器指针：负责周期性触发回调
    rclcpp::TimerBase::SharedPtr timer_;

    // 发布者指针：发布 Twist 消息给小乌龟
    rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr publisher_;

public:
    // 构造函数（node_name 为节点名称）
    explicit TurtleCircle(const std::string& node_name)
        : Node(node_name)      // 调用父类 Node 的构造函数
    {
        // 创建一个 Twist 消息发布者，话题名称 "/turtle1/cmd_vel"，队列长度 10
        publisher_ = this->create_publisher<geometry_msgs::msg::Twist>(
            "/turtle1/cmd_vel", 10);

        // 创建一个定时器：每 1000ms 调用一次 timer_callback()
        timer_ = this->create_wall_timer(
            1000ms,
            std::bind(&TurtleCircle::timer_callback, this)
        );
    }

private:
    // 定时器回调函数，每 1 秒执行一次
    void timer_callback()
    {
        auto msg = geometry_msgs::msg::Twist();   // 创建速度消息对象

        msg.linear.x  = 1.0;   // 小乌龟前进速度（1.0 m/s）
        msg.angular.z = 0.5;   // 小乌龟角速度（弧度/s），让它转圈

        publisher_->publish(msg);   // 发布消息
    }
};

int main(int argc, char * argv[])
{
    rclcpp::init(argc, argv);   // 初始化 ROS2

    // 创建节点对象（节点名叫 turtle_square）
    auto node = std::make_shared<TurtleCircle>("turtle_square");

    rclcpp::spin(node);         // 进入循环，等待并执行回调
    rclcpp::shutdown();         // 关闭 ROS2

    return 0;
}
```

+ `TurtleCircle` **是构造函数名** ✔
+ `(const std::string& node_name)`**是传入参数** ✔
+ `: Node(node_name)`**调用父类构造函数** ✔

这些都是 **正确的**。

🟦 但是还需要补充 1 个关键点：

👉 `: Node(node_name)`**属于 “构造函数初始化列表”**

它不仅仅是“调用父类”，  
而是所有 **需要提前初始化的成员**、**父类**、**常量成员**、**引用成员** 都必须放在这里初始化。

例如：

```cpp
class A {
public:
    A(int x) { }
};

class B : public A {
public:
    B() : A(10)     // 必须在这里初始化父类
    {
        // 这里是构造函数体，不用于初始化父类
    }
};
```

✨ 为什么不能在构造函数内部调用父类构造？

因为：  
✔ 父类必须在子类构造之前完成初始化  
✔ 构造函数体执行时，父类已经初始化完了  
❌ 所以不能在函数体里初始化父类

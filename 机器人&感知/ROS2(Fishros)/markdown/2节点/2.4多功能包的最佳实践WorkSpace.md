## 2.4多功能包的最佳实践WorkSpace
### 创建工作空间
```bash
mkdir -p chapt2_ws/src

这不是创建普通文件夹吗?

$ mv demo_cpp_pkg/ chapt2_ws/src/

$ mv demo_python_pkg/ chapt2 ws/src/

$ rm -rf build/ install/ log/
```

### 构建工作空间下单独功能包

`colcon build --packages-select demo_cpp_pkg`

### 构建工作空间下的功能包依赖情况
```
<depend>rclpy</depend>

<depend>demo_cpp_pkg</depend>
```

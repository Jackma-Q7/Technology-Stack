## 2.2 使用功能包组织Python节点
### 创建
```bash
ros2 pkg create demo_python_pkg --build-type ament_python --license Apache-2.0
```
```
demo_python_pkg
├── demo_python_pkg
├── resource
├── test
├── LICENSE
├── package.xml
├── setup.cfg
└── setup.py
```
### 代码
demo_python_pkg/demo_python_pkg目录下新建python_node

### 注册
setup.py
```
tests_require=['pytest']

entry_points={

'console_scripts':[

'python_node = deme_python_pkg.python_node:main'

],
```
### 声明
打开demo_python_pkg/package.xml，添加依赖信息

`<depend>rclpy</depend>`

### 构建
```
colcon build

ros2 run demo_python_pkg python_node

source install/setup.bash
```
### Python功能包结构分析

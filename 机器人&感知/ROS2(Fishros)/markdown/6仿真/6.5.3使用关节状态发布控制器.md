## 6.5.3使用关节状态发布控制器
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/57223890/1765245146909-99f66f89-142c-4d4e-876b-329076cd186f.png)

出现这一现象的原因是我们将两轮差速插件注释后，就没有节点提供两个轮子到basefootprint之间的 TF 变换了。我们可以使用ros2 control的关节状态控制器，发布 /joint states话题，然后由robot state publisher 转成 TF 数据并发布。

```yaml
controller_manager:
  ros__parameters:
    update_rate: 100   # Hz
    use_sim_time: true

    fishbot_joint_state_broadcaster:
      type: joint_state_broadcaster/JointStateBroadcaster
      # 没有参数也可以留空
```

加载控制器

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/57223890/1765245307935-5cac8355-bd38-4569-b82c-a25d9f509ba4.png)

**在luanch中加入**

```python
# 加载并激活 fishbot_joint_state_broadcaster 控制器
load_joint_state_controller = launch.actions.ExecuteProcess(
    cmd=[
        'ros2', 'control', 'load_controller',
        '--set-state', 'active',
        'fishbot_joint_state_broadcaster'
    ],
    output='screen'
)

return launch.LaunchDescription([
    # 事件动作：当 spawn 机器人结束后执行
    launch.actions.RegisterEventHandler(
        event_handler=launch.event_handlers.OnProcessExit(
            target_action=spawn_entity_node,    # 监听 Gazebo spawn 机器人动作
            on_exit=[load_joint_state_controller]  # 退出后执行加载控制器
        )
    ),

    # ... 其他节点放这里
])
```

## 6.4.7深度相机传感器仿真
因为深度相机坐标系默认前方是z轴，所以我们先在URDF中添加一个虚拟部件来调整方位

```xml
<!-- 定义光学坐标系 link -->
<link name="camera_optical_link"></link>

<!-- camera_link → camera_optical_link 的固定关节 -->
<joint name="camera_optical_joint" type="fixed">
  <parent link="camera_link" />
  <child link="camera_optical_link" />

  <!-- 将普通 camera_link 转换为 ROS 统一的相机光学坐标系 -->
  <origin xyz="0 0 0" rpy="${-pi/2} 0 ${-pi/2}" />
</joint>

```

加入相机插件

```xml
<gazebo reference="camera_link">
  <sensor type="depth" name="camera_sensor">

    <plugin name="depth_camera" filename="libgazebo_ros_camera.so">
      <!-- 发布相机 TF 时使用的坐标系 -->
      <frame_name>camera_optical_link</frame_name>
    </plugin>

    <always_on>true</always_on>
    <update_rate>10</update_rate>

    <camera name="camera">
      <!-- 水平视场角（radian） -->
      <horizontal_fov>1.5009831567</horizontal_fov>

      <image>
        <width>800</width>
        <height>600</height>
        <format>R8G8B8</format>
      </image>

      <!-- 镜头畸变参数（此处设为理想相机，无畸变） -->
      <distortion>
        <k1>0.0</k1>
        <k2>0.0</k2>
        <k3>0.0</k3>
        <p1>0.0</p1>
        <p2>0.0</p2>
        <center>0.5 0.5</center>
      </distortion>

    </camera>

  </sensor>
</gazebo>
```

没有 remapping。

🔍 那默认话题是什么？

**根据 ROS 官方 gazebo_ros_camera 插件规则：**

| 数据类型 | 默认话题 |
| --- | --- |
| 彩色图像 | `/<camera_name>/image_raw` |
| 深度图像 | `/<camera_name>/depth/image_raw` |
| 相机参数 | `/<camera_name>/camera_info` |


其中 `<camera_name>` 就是 **sensor 标签的 name**：

```plain
name="camera_sensor"
```

## 1、 在main执行之前和之后执行的代码可能是什么？
### 阿秀：
**main函数执行之前**，主要就是初始化系统相关资源：

+ 设置栈指针
+ 初始化静态`static`变量和`global`全局变量，即`.data`段的内容
+ 将未初始化部分的全局变量赋初值：数值型`short`，`int`，`long`等为`0`，`bool`为`FALSE`，指针为`NULL`等等，即`.bss`段的内容
+ 全局对象初始化，在`main`之前调用构造函数，这是可能会执行前的一些代码
+ 将main函数的参数`argc`，`argv`等传递给`main`函数，然后才真正运行`main`函数
+ `__attribute__((constructor))`, 让某个函数在 `main()` 之前自动执行。  

**main函数执行之后**：

+ 全局对象的析构函数会在main函数之后执行；
+ 可以用 `atexit` 注册一个函数，它会在main 之后执行;
+ `__attribute__((destructor))`

### GPT:
`main()` 执行之前，可能会做这些事情：  

1. **设置运行环境**
    -  设置栈指针； 
    -  准备堆、栈等运行时资源； 
    -  准备程序运行所需的基础环境。 
2. **初始化全局变量和静态变量**
    -  已初始化的全局变量和 `static` 变量会被放到 `.data` 段，并在启动时初始化； 
    -  未初始化的全局变量和 `static` 变量会被放到 `.bss` 段，并被清零。 

```cpp
int g_num = 10;      // .data 段
static int s_num;    // .bss 段，启动时被初始化为 0
```

3. **初始化 C++ 全局对象**
    -  如果是 C++ 程序，全局对象的构造函数会在 `main()` 之前被调用。 

```cpp
class Test {
public:
    Test() {
        // main 之前执行
    }
};

Test t;
```

4. **执行被标记为 constructor 的函数**
    -  使用 `__attribute__((constructor))` 修饰的函数，会在 `main()` 之前自动执行。 

```cpp
__attribute__((constructor))
void init_func(void) {
    // main 之前自动执行
}
```

5. **准备 **`**main()**`** 的参数**
    -  运行时环境会准备好 `argc`、`argv` 等参数，然后再调用 `main()`。 

`main()` 执行之后，可能会做这些事情：

1. **执行通过 **`**atexit()**`** 注册的函数**

```cpp
#include <stdlib.h>

void cleanup(void) {
    // main 结束后执行
}

int main(void) {
    atexit(cleanup);
    return 0;
}
```

2. **执行 C++ 全局对象的析构函数**
    -  如果程序中有全局对象，它们的析构函数会在 `main()` 结束后执行。 
3. **执行被标记为 destructor 的函数**
    -  使用 `__attribute__((destructor))` 修饰的函数，会在 `main()` 结束后自动执行。 

```cpp
__attribute__((destructor))
void exit_func(void) {
    // main 之后自动执行
}
```

总结

```plain
启动代码
  ↓
初始化 .data 段
  ↓
清零 .bss 段
  ↓
执行全局对象构造函数 / constructor 函数
  ↓
调用 main()
  ↓
执行 atexit 注册的函数
  ↓
执行全局对象析构函数 / destructor 函数
  ↓
程序结束
```

## unique_ptr概述
uinque_ptr代表的是**独占所有权**，它没有拷贝语义(没有赋值构造函数和赋值函数)，只可通过移动操作来**转移**所有权(只有移动语义)，它的三个核心接口：

release() 

返回指向被管理对象的指针，并释放所有权

reset()

替换被管理的对象

swap()

交换被管理的对象

**<font style="color:#DF2A3F;">可以通过release()和reset()转移所有权</font>**

```cpp
        /*if (!p)

    }

```

**std::unique_ptr<CTest> p(new CTest(1));**

**std::unique_ptr<CTest> p2(new CTest(2));**

**p2.reset(p.release()); 这会发生什么简单的概括下？**

 p 把对象“交出去”，p2 先“干掉自己原来的对象”，再接管 p 的对象  

① 创建阶段

```plain
p  -----> CTest(1)
p2 -----> CTest(2)
```

输出：

```plain
CTest1
CTest2
```

② 执行 `p.release()`

```plain
p.release();
```

发生：

+  p 变成空（不再管理对象） 
+  返回 CTest(1) 的裸指针 

此时：

```plain
p   == nullptr
(临时指针) -----> CTest(1)
p2  -----> CTest(2)
```

⚠️ 注意：此时如果没人接管，这个对象就泄漏了

③ 执行 `p2.reset(...)`

```plain
p2.reset(刚才那个指针)
```

发生两件事：

第一步：先删除 p2 原来的对象

```plain
delete CTest(2)
```

输出：

```plain
~CTest()2
```

第二步：接管 CTest(1)

```plain
p2 -----> CTest(1)
```

④ 最终状态

```plain
p   == nullptr
p2 -----> CTest(1)
```

⑤ 程序结束时

`p2` 析构 → 删除 CTest(1)

输出：

```plain
~CTest()1
```

## 问题1：CTest p4 = p.get();获得p对象的指针，但是不能delete，只能p4 =nullptr吗？

👉 `get()` = 看地址，不负责释放，也不能释放

真正危险的点（你要特别注意）

```cpp
CTest* p4;
{
    std::unique_ptr<CTest> p(new CTest(1));
    p4 = p.get();
}
p4->xxx;  // ❌ 危险！悬空指针
```

因为：

+ `p` 出作用域 → 对象被 delete 
+ `p4` 还指着那块内存 → **野指针，只能p4 =nullptr**

**std::shared_ptr<int> sp1(p);**

## 问题2：这个是delete p，sp1.reset对吧？

释放（两种方式）

✔ 方式1：作用域结束

```plain
{
    std::shared_ptr<int> sp1(p);
} // 自动 delete p
```

✔ 方式2：手动 reset

```plain
sp1.reset();  // 内部 delete p
```

但是p被std::shared_ptr接管了，就不能delete了

```cpp
#include<memory>
#include<iostream>

class B;
class A
{
public:
	A()
	{
		std::cout << "A()" << std::endl;
	}

	~A()
	{
		std::cout << "~A()" << std::endl;
	}

	void SetB(const std::shared_ptr<B> &pb)
	{
		m_pB = pb;
	}
private:
	std::shared_ptr<B> m_pB;
};

class B
{
public:
	B()
	{
		std::cout << "B()" << std::endl;
	}

	~B()
	{
		std::cout << "~B()" << std::endl;
	}

	void SetA(const std::shared_ptr<A>& pA)
	{
		m_pA = pA;
	}
private:
	//std::shared_ptr<A> m_pA;
	std::weak_ptr<A> m_pA;
};

int main()
{
	{
		std::shared_ptr<A> pA = std::make_shared<A>();
		std::shared_ptr<B> pB = std::make_shared<B>();

		pA->SetB(pB);
		pB->SetA(pA);

		std::cout << pA.use_count() << std::endl;
		std::cout << pB.use_count() << std::endl;
	}

```

**std::shared_ptr<A> pA = std::make_shared<A>();**

**pA是一个什么东西  ？**

pA 是一个“智能指针对象”（不是普通指针）

执行这句后：

```cpp
auto pA = std::make_shared<A>();
```

内存大概是这样👇

```plain
栈上：
  pA（一个 shared_ptr 对象）

堆上：
  [ 控制块 + A对象 ]
```

你可以理解为：

```plain
pA ───────► [ 控制块 ]
                │
                ▼
               A对象
```

**void SetA(const std::shared_ptr<A>& pA)传入的参数是什么？**

std::shared_ptr<A> 类型（智能指针对象）

&                  引用（不拷贝）

const              只读（不能修改pA本身）

```plain
SetA(p);
```

👉 实际是：

```plain
pA 绑定到 p（同一个对象，不拷贝）
```

👉 所以此时：

```plain
没有增加引用计数 ❗
```

**&这是引用，我还以为是取PA的地址传进去  ？**

类型声明里：& 表示“引用”  
表达式里：& 表示“取地址”

什么是“引用”（核心理解）

👉 引用本质：

给一个已有变量起一个“别名”

✅ 最简单例子

```cpp
int a = 10;
int& ref = a;
```

👉 内存不是复制，而是：

```cpp
a   = 10 
ref = a 的另一个名字
```

👉 所以：

```cpp
ref = 20;
```

👉 等价于：

```cpp
a = 20;
```

1️⃣ 引用必须初始化  
2️⃣ 一旦绑定，不能改绑  
3️⃣ 没有独立内存（只是别名）

值传递         调用方式setA(p)     安全中

引用（推荐）    调用方式setA(p)    安全高

地址            调用方式setA(&p)   安全低

对比三种写法

我们用同一个例子👇

```cpp
std::shared_ptr<A> p = std::make_shared<A>();
```

✅ ① 值传递（拷贝）

```cpp
void SetA(std::shared_ptr<A> pA)
```

调用：

```plain
SetA(p);
```

👉 发生：

```plain
p ──► 控制块（count=1）

调用后：

p ──┐
pA ─┘──► 控制块（count=2）
```

👉 特点：

+  ✔ 会拷贝 
+  ✔ 引用计数 +1 
+  ❌ 有性能开销 

✅ ② 引用（你现在用的）

```cpp
void SetA(const std::shared_ptr<A>& pA)
```

调用：

```cpp
SetA(p);
```

👉 发生：

```cpp
pA ≈ p（同一个对象）
```

👉 内存：

```cpp
p ───► 控制块（count=1）
pA ──┘（只是别名）
```

👉 特点：

+  ✔ 不拷贝 
+  ✔ 不增加引用计数 
+  ✔ 性能最好 
+  ✔ 最常用 

⚠️ ③ 指针（你刚才误解的）

```cpp
void SetA(const std::shared_ptr<A>* pA)
```

调用：

```cpp
SetA(&p);
```

👉 内存：

```plain
p        ───► 控制块
& p      ───► p 的地址
pA       ───► p 的地址
```

👉 使用时必须：

```cpp
(*pA)->xxx;
```

👉 特点：

+  ❌ 需要手动取地址 
+  ❌ 容易出错（nullptr） 
+  ❌ 可读性差

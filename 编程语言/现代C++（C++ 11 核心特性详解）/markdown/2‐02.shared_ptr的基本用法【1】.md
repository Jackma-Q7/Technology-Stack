**智能指针**

智能指针的基本原理就是通过RAII实现对内存的管理，从C++ 11开始已经不推荐再使用裸指针

智能指针支持裸指针的所有操作，如：*，++，--，+=，<，>

C++ 11 加入了**<font style="color:#DF2A3F;">shared_ptr，unique_ptr，weak_ptr，</font>**(还可以算上Boost库中的socpe_ptr)，三种智能指针都有各自的语义，对所管理的对象代表了不同的所有权，适用于不同的场景

**shared_ptr概述**

共享所有权，具有复制语义，多个shared_ptr指向同一个对象时，每个shared_ptr的引用计数都会记录指向该对象的shared_ptr的数量，当最后一个指向对象（和共享计数）的 shared_ptr 析构时，它会删除对象和共享计数，通过use_count方法可以获取shared_ptr对象的共享计数值

```cpp
#include <memory>
#include <iostream>

class test
{
public:
	test(int i):m_i(i)//构造函数的初始化列表m_i = i;
	{
		std::cout << "test()" << m_i <<std::endl;
	}

	~test()
	{
		std::cout << "~test()" <<  std::endl;
	}

private:
	int m_i;
};

int main()
{

	//裸指针
	test *p = new test(1);
	std::shared_ptr<test> sp(p);
	//std::shared_ptr<test> sp1(new test());

	//{
	//	//shared_ptr裸指针
	//	std::shared_ptr<test> sp2(sp);
	//	std::cout << "use count " << sp2.use_count() << std::endl;
	//}


	//std::cout << "use count " << sp.use_count();
	test* p2 = new test(2);
	sp.reset(p2);//让 sp 不再管理原来的 test(1)，改为管理新的 test(2)。

	std::system("pause");
}
```

std::shared_ptr<test>sp(p);

这句把裸指针 p 交给 sp 管理。也就是说，从这里开始，这块内存应该由 sp 负责释放，不应该再手动 delete p 了。因为 shared_ptr 会在最后一个拥有者销毁时自动 delete。

```cpp
test *p = new test(1);
std::shared_ptr<test> sp(p);
```

但不算最好。更推荐直接写：

```cpp
std::shared_ptr<test> sp(new test(1));
```

或者更推荐：

```cpp
auto sp = std::make_shared<test>(1);
```

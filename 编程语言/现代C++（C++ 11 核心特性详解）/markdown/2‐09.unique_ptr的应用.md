## unique_ptr的应用
实现工厂模式

&emsp;&emsp;配合shared_ptr实现工厂模式

容器存入unique_ptr

&emsp;&emsp;unique_ptr不支持拷贝语义，直接将一个unique_ptr对象存入容器是不行的，必须通过std::move将unqiue_ptr对象“移动”到容器

unique_ptr支持动态数组

&emsp;&emsp;unique_ptr有个数组版本，支持动态数组

&emsp;&emsp;**<font style="color:#DF2A3F;">boost 提供了一个socped_ptr的智能指针，它不可复制，也不可转移，代表完全所有权</font>**

```cpp
#include <memory>
#include <iostream>
#include <string>
class CTest
{
public:
CTest()
{
    std::cout << "CTest" << std::endl;
}

~CTest()
{
    std::cout << "~CTest" << std::endl;
}
};


class CTest1 :public CTest
{
public:
CTest1()
{
    std::cout << "CTest1" << std::endl;
}

~CTest1()
{
    std::cout << "~CTest1" << std::endl;
}
};

class CTest2 :public CTest
{
public:
CTest2()
{
    std::cout << "CTest1" << std::endl;
}

~CTest2()
{
    std::cout << "~CTest1" << std::endl;
}
};

std::unique_ptr<CTest> CTestMake(const std::string& str)
{
    std::unique_ptr<CTest> p;
    if ("Test1" == str)
    {
        p.reset(new CTest1);
    }
    else if ("Test2" == str)
    {
        p.reset(new CTest2);
    }
    else
    {
        p.reset(new CTest);
    }

    return p;
}

int main()
{
    std::unique_ptr<CTest> p = CTestMake("Test1");
    std::shared_ptr<CTest> p1 = CTestMake("Test2");
}
```

打印结果

CTest

CTest1

CTest

CTest2

~CTest2

~CTest

~CTest1

~CTest

**工厂函数 **`CTestMake`**？**

这个函数的意思很简单：

+  传 `"Test1"`，就创建 `CTest1`
+  传 `"Test2"`，就创建 `CTest2`
+  否则创建 `CTest`

但是返回类型统一都是：

```plain
std::unique_ptr<CTest>
```

也就是：**虽然实际创建的可能是子类对象，但对外统一返回父类智能指针。**

```cpp
#include <memory>
#include <iostream>
#include <vector>
int main()
{
    std::unique_ptr<int> p(new int(18));
    std::vector < std::unique_ptr<int>> v;
    v.push_back(std::move(p));

    if (!p)
    {
        std::cout << "is empty" << std::endl;
    }
}
```

```plain
std::vector<std::unique_ptr<int>> v;
```

这是定义了一个 vector，里面存的每个元素都是：

```plain
std::unique_ptr<int>
```

也就是说，这个容器里装的是“独占指针”。

```plain
v.push_back(std::move(p));
```

这里为什么必须 `std::move(p)`？

因为 `unique_ptr` 的特点就是：

+ **不能复制**
+ **只能转移所有权**

## 问题1：返回类型都是std::unique_ptr<CTest>？

👉 是的，CTestMake 的返回类型始终是 std::unique_ptr<CTest>，不会变。

✅ 那为什么这一句还能成立？
std::shared_ptr<CTest> p1 = CTestMake("Test2");

关键点在这里：

👉 shared_ptr 有一个构造函数，可以接收 unique_ptr（右值）

也就是说编译器帮你做了这件事：

`std::unique_ptr<CTest> temp = CTestMake("Test2");`

`std::shared_ptr<CTest> p1(std::move(temp));`

🔥 本质理解（非常重要）

1️⃣ unique_ptr 是独占所有权

只能有一个人拥有对象

不允许拷贝（只能移动）

2️⃣ shared_ptr 是共享所有权

多个指针可以共同管理对象

内部有引用计数

👉 p1 的类型就是：std::shared_ptr<CTest>

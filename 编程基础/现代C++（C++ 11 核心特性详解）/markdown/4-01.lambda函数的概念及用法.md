## 概述
lambda是C++ 11引入的新特性

其它语言中也有lambda，比如javascript

lambda表示匿名函数，属于可调用对象，特点是就地定义就地使用

&emsp;&emsp;在C++中，lambda是一种语法糖，编译器会将它翻译成函数对象。所以它并不是一个"黑科技"。引入lambda的目的就是要就地书写，就地使用，提供一种简化代码的手段。

## 语法及用法
形式

捕获列表+参数列表+函数体

1.[ 捕获 ] ( 形参 ) -> ret { 函数体 }

2.[ 捕获 ] ( 形参 ) { 函数体 }

3.[ 捕获 ] { 函数体 } 

用法

&emsp;&emsp;在任何需要可调用对象的接口，都可以传入一个lambda匿名函数

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
int main()
{
    auto f = [](int i)->int {std::cout << i << std::endl; return 18; };
    std::cout << f(118) << std::endl;

    auto f1 = [](int i) {std::cout << i << std::endl; return 18; };
    std::cout << f1(1118) << std::endl;

    auto f2 = [] {std::cout << "lambda" << std::endl; return 18; };
    std::cout << f2() << std::endl;

    std::vector<int> ints = { 1,2,3,4,5,6 };

    std::for_each(ints.begin(), ints.end(), [](const int& v) {std::cout << v << " " << std::endl; });
}
```

```cpp
auto f = [](int i)->int {std::cout << i << std::endl; return 18; };
```

这行定义了一个 lambda，并交给变量 `f` 保存。

可以拆成几部分看：

```cpp
[]          // 捕获列表
(int i)     // 参数列表
->int       // 返回值类型
{ ... }     // 函数体
```

意思就是：

+  这是一个匿名函数 
+  接收一个 `int` 参数 `i`
+  返回值类型是 `int`
+  先打印 `i`
+  再返回 `18`

相当于你写了一个函数：

```cpp
int test(int i)
{
    std::cout << i << std::endl;
    return 18;
}
```

只是 lambda 没有名字。

调用它

```cpp
std::cout << f(118) << std::endl;
```

这里先执行 `f(118)`。

`f(118)` 进去后做两件事：

1.  打印 `118`
2.  返回 `18`

然后外面的 `std::cout` 再把返回值 `18` 打印出来。

所以这一段输出是：

```cpp
118
18
```

**第五部分：for_each**

```cpp
std::for_each(ints.begin(), ints.end(), [](const int& v) {std::cout << v << " " << std::endl; });
```

这个是重点。

`std::for_each` 的意思是：

**对区间里的每一个元素，都执行一次后面的操作。**

这里的区间是：

```cpp
ints.begin(), ints.end()
```

也就是整个 `ints` 容器。

后面的 lambda：

```cpp
[](const int& v) {std::cout << v << " " << std::endl; }
```

意思是：

+  每次拿到一个元素 `v`
+  把它打印出来 

所以它会依次处理：

+  1 
+  2 
+  3 
+  4 
+  5 
+  6 

为什么写 `const int& v`

```cpp
const int& v
```

意思是：**用常量引用接收当前元素**

好处：

+  不会拷贝一份新值 
+  不能修改原数据 
+  效率更好一些 

这里就相当于“只读地看一下每个元素”。

当然这里写成：

```cpp
int v
```

也可以，只是会拷贝。

## 捕获对象的this指针
&emsp;&emsp;[this]捕获当前类中的this指针，让lambda表达式拥有和当前类成员相同的访问权限,捕获this的目的是可以在lambda中使用当前类的成员函数，成员变量

```cpp
#include<iostream>
#include <vector>
#include <functional>

typedef std::function<void()> Func;
class CTest
{
public:
    CTest()
    {
        _vecValue.push_back(18);
        _vecValue.push_back(118);
    }


public:
    void Print()
    {
        [this] (){
            for (auto i : _vecValue)
            {
                std::cout << i << std::endl;
            }
        }();
    }

    Func Get()
    {
        return [this]() {
            for (auto i : _vecValue)
            {
                std::cout << i << std::endl;
            }
        };
    }
private:
    std::vector<int> _vecValue;
};

int main()
{
    CTest t1;
    t1.Print();

    auto f = t1.Get();
    f();

    CTest *t2 = new CTest();
    auto f1 = t2->Get();
    delete t2;
    t2 = nullptr;

    f1();

}
```

一、先看 `Print()`

```cpp
void Print()
{
    [this] (){
        for (auto i : _vecValue)
        {
            std::cout << i << std::endl;
        }
    }();
}
```

这段最重要的是这个：

```cpp
[this] () { ... }
```

意思是：**lambda 捕获当前对象的 **`this`** 指针**。

也就是把“当前对象是谁”带进 lambda 里。

**为什么要捕获**`this`

因为 `_vecValue` 是成员变量，不是局部变量。

在 lambda 里访问成员变量，本质上其实是：

```cpp
this->_vecValue
```

所以想在 lambda 里用 `_vecValue`，就得能拿到当前对象的 `this`。

这段代码等价理解

```cpp
[this] (){
    for (auto i : _vecValue)
        {
            std::cout << i << std::endl;
        }
}();
```

你可以脑子里理解成：

```cpp
[this] (){
    for (auto i : this->_vecValue)
        {
            std::cout << i << std::endl;
        }
}();
```

最后这个 `()` 是什么

注意这里：

```cpp
}();
```

lambda 定义完后，后面立刻加了 `()`，表示 **定义完立刻调用**。

就像：

```plain
func();
```

所以 `Print()` 的意思就是：

+  定义一个捕获 `this` 的 lambda 
+  然后立刻执行它 
+  打印当前对象里的 `_vecValue`

二、再看 `Get()`

```cpp
Func Get()
{
    return [this]() {
        for (auto i : _vecValue)
            {
                std::cout << i << std::endl;
            }
    };
}
```

这个和 `Print()` 的区别非常重要。

这里不是立即调用，而是：

```cpp
return [this]() { ... };
```

也就是：**返回一个 lambda 对象**。

这个 lambda 里面也保存了 `this`。

`Get()` 返回了什么

返回的是一个 `std::function<void()>`，里面装着这个 lambda。

所以外面拿到后，可以以后再调用：

```cpp
auto f = t1.Get();
f();
```

三、看 `main()`

第一段

```cpp
CTest t1;
t1.Print();
```

先创建对象 `t1`。

它内部的 `_vecValue` 是：

```cpp
18
118
```

调用：

```cpp
t1.Print();
```

进入 `Print()` 后，lambda 立刻执行，打印：

```cpp
18
118
```

第二段

```cpp
auto f = t1.Get();
f();
```

`auto f = t1.Get();`

这里调用 `Get()`，返回一个 lambda。

这个 lambda 捕获了 `t1` 的 `this` 指针。

也就是说，`f` 里面记住了：  
“我要操作的是 `t1` 这个对象”。

`f();`

执行这个 lambda，打印 `t1._vecValue`：

```cpp
18
118
```

这一段是安全的，因为 `t1` 还活着。

第三段

```cpp
CTest *t2 = new CTest();
auto f1 = t2->Get();
delete t2;
t2 = nullptr;

f1();
```

这里就是重点坑。

第一步

```cpp
CTest *t2 = new CTest();
```

在堆上创建一个 `CTest` 对象。

它内部 `_vecValue` 也是：

```cpp
18
118
```

第二步

```cpp
auto f1 = t2->Get();
```

这里返回一个 lambda，lambda 捕获了 `this`。

注意，这里的 `this` 就是 `t2` 指向的那个对象地址。

也就是说，`f1` 里面保存的是：

**那个堆对象的地址**

不是拷贝了一份 `_vecValue`，只是记住了对象地址。

第三步

```cpp
delete t2;
t2 = nullptr;
```

对象已经被释放了。

也就是原来 `this` 指向的那块内存，已经无效了。

这里：

```cpp
t2 = nullptr;
```

只是把指针变量 `t2` 自己清空。

**不会影响 **`f1`** 里面已经保存的那个旧地址。**

第四步

```cpp
f1();
```

这时 `f1` 还会去用它保存的 `this` 指针访问：

```cpp
_vecValue
```

但那个对象已经被 `delete` 了。

所以这是：

**未定义行为**

可能出现的情况有：

+  程序崩溃 
+  看起来还能打印 18 和 118 
+  打印乱码 
+  运行结果每次都不一样 

都可能。

四、为什么会出问题

因为：

```cpp
[this]
```

捕获的是 **this 指针**，不是整个对象内容。

也就是说它只保存了一个地址。

对象活着时，这个地址有效。  
对象死了，这个地址就悬空了。

所以问题不是 lambda 本身，而是：

**lambda 里拿着已经失效的对象地址。**

五、你可以把它想成这样

比如对象地址是：

```cpp
this = 0x1000
```

`Get()` 返回的 lambda 实际上像在保存：

```plain
“以后我要去 0x1000 这个对象里取 _vecValue”
```

如果这个对象还在，没问题。  
但 `delete t2` 后，`0x1000` 这块对象已经没了。

再去访问，就是错的。

六、这段代码的安全和危险部分

安全的

```cpp
CTest t1;
auto f = t1.Get();
f();
```

因为 `t1` 还存在，lambda 中的 `this` 有效。

危险的

```cpp
CTest *t2 = new CTest();
auto f1 = t2->Get();
delete t2;
f1();
```

因为对象已经销毁，lambda 里保存的 `this` 已失效。

七、`Print()` 和 `Get()` 的本质区别

`Print()`

```plain
[this](){ ... }();
```

是 **立即执行**。

只要执行时对象还活着，就安全。

`Get()`

```plain
return [this](){ ... };
```

是 **把 lambda 返回出去，以后再执行**。

这时候就要特别小心：  
**以后执行时，对象还在不在？**

## 问题1：lambda的this才能用成员函数
&emsp;&emsp;lambda传入this可以用对象里的成员变量？但是我记得成员函数也可以用成员变量呢？为啥lambda传入必须this才可以用对象里的成员变量？  

 👉 **成员函数自带 **`this`**，但 lambda 默认没有 **`this`**，所以必须手动捕获。**

为什么成员函数可以直接用成员变量？

你写的：

```cpp
class CTest {
public:
void Print() {
    std::cout << _vecValue[0] << std::endl;
}
private:
std::vector<int> _vecValue;
};
```

你觉得你在用：

```cpp
_vecValue
```

但编译器实际上帮你变成了：

```cpp
this->_vecValue
```

也就是说：

👉 **成员函数内部默认隐含一个 **`this`** 指针**

所以你才能直接用成员变量。

lambda 为什么不行？

看这个：

```cpp
[]() {
    std::cout << _vecValue << std::endl; // ❌ 错误
};
```

这里会报错：

👉 因为 lambda 本质上是一个“独立的函数对象”，不是类成员函数

它没有：

```plain
this
```

所以它根本不知道 `_vecValue` 是谁的。

lambda 的本质（非常关键）

这个 lambda：

```cpp
[this]() {
    std::cout << _vecValue << std::endl;
};
```

大致等价于（简化理解）：

```cpp
class Lambda {
public:
Lambda(CTest* p) : this_(p) {}

void operator()() {
    std::cout << this_->_vecValue << std::endl;
}

private:
CTest* this_;
};
```

也就是说：

👉 `[this]`**本质就是把 `this`指针存进 lambda 对象里**

除了 `[this]`，lambda 还可以捕获：

```plain
[a]        // 按值捕获
[&a]       // 按引用捕获
[=]        // 捕获所有变量（值）
[&]        // 捕获所有变量（引用）
```

## 问题2：成员函数定义区别？
 解释下这两种成员函数定义的区别？

`typedef std::function<void()> Func; Func Get() 和void Print()  `

一、先看它们的定义

1️⃣ `Print()`

```plain
void Print()
```

意思：

+  无返回值 
+  调用它就**直接执行逻辑**

👉 就是普通成员函数

2️⃣ `Get()`

```cpp
typedef std::function<void()> Func;

Func Get()
```

等价于：

```cpp
std::function<void()> Get()
```

意思：

+  返回一个“可调用对象”（函数、lambda等） 
+  调用它不会执行逻辑，而是**返回一个函数**

二、用人话理解（最关键）

✅ `Print()`

👉 “我帮你干活”

```cpp
t1.Print();
```

立刻执行，直接输出：

```cpp
18
118
```

✅ `Get()`

👉 “我不给你干活，我给你一个工具，你自己决定什么时候用”

```cpp
auto f = t1.Get();
f();
```

流程是：

1. `Get()` 返回一个函数（lambda） 
2.  你自己调用 `f()` 才执行 

三、对比执行流程（非常重要）

`Print()`

```cpp
t1.Print();
```

流程：

```cpp
调用 Print()
↓
lambda 立刻执行
↓
打印数据
```

`Get()`

```plain
auto f = t1.Get();
f();
```

流程：

```plain
调用 Get()
   ↓
返回 lambda（还没执行）
   ↓
调用 f()
   ↓
lambda 执行
   ↓
打印数据
```

## 问题3： function，bind，lambda  
👉 lambda：用来“写函数”  
👉 bind：用来“改函数（参数/绑定）”  
👉 std::function：用来“装函数（统一类型）”

1️⃣ lambda —— 写函数

👉 本质：**快速定义一个匿名函数**

```cpp
auto f = [](int x) {
    return x + 1;
};
```

相当于：

```cpp
int f(int x) {
    return x + 1;
}
```

✔ 临时用  
✔ 不用起名字  
✔ 可以捕获变量（最重要）

2️⃣ bind —— 改函数

👉 本质：**把一个函数“重新包装”，改变参数**

原函数

```cpp
int add(int a, int b)
{
    return a + b;
}
```

用 bind 改造

```cpp
auto f = std::bind(add, std::placeholders::_1, 10);
```

变成：

```cpp
f(x) == add(x, 10)
```

👉 把第二个参数固定成 10

✔ 固定参数  
✔ 改参数顺序  
✔ 减少参数个数

3️⃣ function —— 装函数

👉 本质：**统一所有“可调用对象”的类型**

```cpp
std::function<int(int)> f;
```

意思是：

👉 “只要你能像 `int(int)` 一样调用，我就能装你”

可以装：

```cpp
f = add;
f = [](int x){ return x + 1; };
f = std::bind(add, _1, 10);
```

三者关系（核心图景）

```plain
        lambda      bind
           ↓          ↓
        （产生可调用对象）
                 ↓
           std::function
        （统一存储 + 调用）
```

结合成一段代码（你就彻底通了）

```cpp
#include <iostream>
#include <functional>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    // 1️⃣ lambda：写一个函数
    auto f1 = [](int x) {
        return x + 1;
    };

    // 2️⃣ bind：改函数
    auto f2 = std::bind(add, std::placeholders::_1, 10);

    // 3️⃣ function：统一存储
    std::function<int(int)> func;

    func = f1;
    std::cout << func(5) << std::endl; // 6

    func = f2;
    std::cout << func(5) << std::endl; // 15
    //👉 std::function 就像一个“函数变量”，可以反复装不同函数，
    //每次赋值都会替换旧的，不会冲突。
}
```

再用一句人话帮你彻底记住

👉 **lambda 是“写刀的人”，bind 是“改刀的人”，function 是“装刀的盒子”。**

你现在这个阶段最重要的理解

你已经可以这样理解整个体系了：

👉 **函数在 C++ 里可以像数据一样传来传去**

而这三样东西分别负责：

+ **lambda：创造函数**
+ **bind：改造函数**
+ **function：存储函数**

最终一句话总结（最标准）

👉 **lambda 生成函数，bind 调整函数，function 统一管理函数。**

# 3-1.function和bind概念及用法
## 概述
&emsp;&emsp;function和bind是C++11引入的非常重要的特性，它们提供了一种新的回调实现机制，达到了C#中的委托的同样效果

## 可调用对象
&emsp;&emsp;在C++中函数，函数指针，指向类的成员函数指针，函数对象(重载了调用运算符的类)，lambda

**<font style="color:#DF2A3F;">1. 函数 </font>**

```cpp
int func(int a,int b) 
{       
    return a+b;
}
int c = func(10,8);
```

**<font style="color:#DF2A3F;">2. 函数指针</font>**

```cpp
int (*AddFunc)(int a,int b);
AddFunc = func;
AddFunc();
```

**<font style="color:#DF2A3F;">3. 函数对象</font>**

```cpp
struct CAdd
{
    int operator()(int a,int b)
    {
    ...
    }
}

CAdd add;
int r = add(10,8)
```

**<font style="color:#DF2A3F;">4. lambda表达式(匿名函数)</font>**

## 可调用对象的类型
&emsp;&emsp;可调用对象都是有类型的，很典型的如函数对象，它本质就一个重载了调用运算符的类，不同的类当然类型也不相同

&emsp;&emsp;函数和函数指针，它们的类型是由其返回值类型和实参类型决定，int func(int a,int b)和void func()就不是同一个类型。它们对应的指针也是不同的类型，不能相互赋值

&emsp;&emsp;很显然函数对象与函数，函数指针也不是同一类型

## 调用形式
&emsp;&emsp;调用形式指明了调用返回的类型及传递给调用的实参类型，如下，就表示一种调用形式

    int (int,int)

不同的可调用对象可能会有相同的调用形式

```cpp
   int add(int a,int b); //函数
    struct CAdd
   {
        int operator()(int a, int b)
        {
               ...
        }
   }; //函数对象
```

&emsp;&emsp;那么上述的函数add和函数对象CAdd的调用形式都是int (int,int)，尽管它们的调用形式都一样，但是它们不是同一个类型，我们可以通过函数指针指向add，但是不能指向CAdd函数对象。

`std::map<std::string,int(*)(int,int)> functions;`

//我们可以将函数add保存在functions中，却不能将CAdd放入map

`functions.insert("add",add)`

## function的用法
&emsp;&emsp;**<font style="color:#DF2A3F;">同一种调用形式的可调用对象的类型可能不同，可以通过function将其统一起来</font>**，function是一个模板，当创建一个具体的function类型时必须提供该function类型能够表示的对象的调用信息。

function<int(int,int)>

&emsp;&emsp;声明了一个function类型，它可以表示接受两个int,返回一个int的可调用对象  
**std::function 是一个“通用函数容器”，可以统一存储并调用任何可调用对象（函数、lambda、bind等）。**

```cpp
#include <functional>
#include <iostream>

int add(int a, int b)
{
    return a + b;
}

struct CAdd
{
    int operator()(int a, int b)
    {
        return a + b;
    }
};

int main()
{
    std::function<int(int, int)> f = add;
    std::cout << f(10, 8) << std::endl;

    //std::function<int(int, int)> f2 = CAdd();
    std::cout << f(11, 9) << std::endl;

    int(*fp)(int, int) = add;
    //std::function<int(int, int)> f3 = fp;
    std::cout << f(12, 10) << std::endl;

    std::function<void(int)> f1;
    if (!f1)
    {
        std::cout << "f1 can't callable" << std::endl;
    }
    
    f1(18);

}
```

`std::function` 就是一个“函数包装器”，可以统一装普通函数、函数指针、仿函数，但调用前要保证里面真的有东西。

## bind的用法
它接受一个可调用对象，生成一个新的可调用对象来适应原对象的参数列表

`auto newCallable = bind(callable,agr_list);`

常用用法包括下面两种：

1.将多元(参数个数为n,n>1)可调用对象转成一元或(n-1)元可调用对象

2.将对象的成员函数转换成调用对象

**<font style="color:#DF2A3F;">为什么需要 bind（核心原因）</font>**

1️⃣先看成员函数：

```cpp
struct A
{
void print(int x)
{
    std::cout << x << std::endl;
}
};
```

👉 这个函数**不能直接这样用**：

```cpp
A::print(10);   // ❌ 错
```

👉 因为它需要一个对象：

```cpp
A a;
a.print(10);    // ✔ 正确
```

---

❗关键点

👉 成员函数本质是：

```cpp
void print(A* this, int x);
```

👉 所以必须有对象（this）

---

🔧 2️⃣ bind 在干嘛？

```cpp
#include <functional>

A a;

auto f = std::bind(&A::print, &a, std::placeholders::_1);
```

👉 这句话做了什么？

👉 **把“成员函数 + 对象”绑定在一起，生成一个新函数对象**

---

🧩 3️⃣ 转换结果是什么？

```cpp
f(10);
```

👉 等价于：

```cpp
a.print(10);
```

---

📦 4️⃣ 你可以这样理解

👉 原始：

```cpp
a.print(x);
```

👉 bind 之后：

```cpp
f(x);
```

👉 变成了“普通函数调用形式”

---

⚙️ 5️⃣ 参数解释（必须看懂）

```cpp
std::bind(&A::print, &a, std::placeholders::_1);
```

| 部分 | 含义 |
| --- | --- |
| `&A::print` | 成员函数指针 |
| `&a` | 绑定的对象（this） |
| `_1` | 占位符，表示未来传进来的参数 |


---

🔥 6️⃣ 为什么说“转换成调用对象”

👉 因为结果：

```cpp
auto f = ...
```

👉 `f` 是一个**函数对象（可调用对象）**

```cpp
f(10);   // 可以像函数一样调用
```

---

🎯 7️⃣ 对比一下（你就彻底懂了）

❌ 成员函数（不能直接用）

```cpp
&A::print
```

👉 不能直接调用

---

✅ bind 后

```cpp
auto f = bind(...)
```

👉 可以直接：

```cpp
f(10);
```

🧠 8️⃣ 再给你一个更直观例子

```cpp
struct A
{
int add(int x, int y)
{
    return x + y;
}
};

A a;

auto f = std::bind(&A::add, &a, 10, std::placeholders::_1);
```

👉 这里发生了什么？

```cpp
f(5);
```

👉 等价于：

```cpp
a.add(10, 5);
```

👉 第一个参数被“固定”了

```cpp
#include <functional>
#include <iostream>

int add(int a, int b)
{
    return a + b;
}

int add1(int a, int b, int c)
{
    return a + b + c;
}

class CTest
{
public:
    CTest(int v) :v_(v)
    {

    }

    int Add(int a)
    {
        return a + v_;
    }

private:
    int v_;
};

int main()
{   //1.将可调用的对象的参数个数由多变少的转换
    std::function<int(int)> f = std::bind(add, std::placeholders::_1, 8);
    std::cout << f(10) << std::endl;

    std::function<int(int, int)> f2 = std::bind(add1, std::placeholders::_1, std::placeholders::_2, 18);
    std::cout << f2(10, 10) << std::endl;

    //std::function<int*(int)> f3 = std::bind(add, std::placeholders::_1, 118);
    std::function<float(int)> f4 = std::bind(add, std::placeholders::_1, 118);

    //2.将对象的成员函数转换为课调用对象
    CTest c(0);
    /*std::function<int(int)>*/ auto f5 = std::bind(&CTest::Add, &c, std::placeholders::_1);
    std::cout << f5(111) << std::endl;
    std::system("pause");
}
```

# 6-1.使用chrono库处理时间
## 对于时间处理的需求
**1.获取当前时间，比如记录日志，精度一般到毫秒**

**2.计算时间间隔，比如判断代码块的运行时长**

3.获取日期，日期换算

4.定时器

&emsp;&emsp;以上是在开发中对时间处理的最常见的4点需求，并且是与平台无关，要求跨平台日期处理更多的是业务层代码中，时间的处理在底层

## OS提供的API
时间的相关API，有两个使用相当广泛的API

&emsp;&emsp;`time_t time() `//返回从1970-01-01 00:00:00 +0000 (UTC)的秒数 **(C语言标准提供)**

&emsp;&emsp;`int gettimeofday(struct timeval *tv,struct timezone *tz)` //返回指定时区 回从1970-01-01 00:00:00 +0000 (UTC)的秒数及微秒

&emsp;&emsp;**time()是跨平台的，但是它的精度只是到了秒，gettimeofday虽然精度到了微秒，但它是linux下的API。当然windows也提供相应的API，但是用法就不同了。**

定时相关

&emsp;&emsp;一种跨平台的定时器，是通过select函数实现(设置timeout参数)

**需要实现高精度，跨平台的时间(日期)处理API**

## C++11中的日期和时间处理
**包括两种方式：**

**1.C语言风格的方式，在time.h头文件包括一系列的API，在C++11中是被包含在ctime头文件中**

&emsp;&emsp;time() 获取时间，用秒数表示，返回一个time_t类型

&emsp;&emsp;ctime() 传入一个**time_t**类型，返回日期字符串

&emsp;&emsp;localtime() 传入一个**time_t**类型，获取一个tm结构体，其中包括了年，月，日，时，分，秒

&emsp;&emsp;**精度是到秒**

**2.C++ 11引入的chrono库**

## chrono库
&emsp;&emsp;chrono库是C++11提供**跨平台**，**强类型**的日期，时间处理库，它提供的功能覆盖了前面提出的前三点需求，它没提供定时相关的功能

&emsp;&emsp;对时间，日期的处理，它引入了三个基本概念：

1.时间点

&emsp;&emsp;比如12：05: 00 表示一个时间点，比如2021-01-01 13:00:00也表示一个时间点

2.时间间隔

&emsp;&emsp;两个时间点的差值

3.时间(时钟)

&emsp;&emsp;时间的通俗概念，包含了时间点，时间间隔，日期

## clock(时间/时钟)
&emsp;&emsp;Clock 跟time_t time()返回值的意义类似，代表这从时间纪元(不一定是从1970-01-01 00:00:00 +0000开始了)，到现在的"距离"，这个"**距离**"有不同的精度

&emsp;&emsp;C++ 11中包含三种clock类型: system_clock，steady_clok，high_resolution_clock

&emsp;&emsp;分别对应了不同的精度

&emsp;&emsp;每一种clock中都定义了特定的duration及time_point类型(因为精度不同)

```cpp
#include <chrono>
#include <iostream>
using namespace std;
using namespace chrono;

int main()
{
    // chrono中常见的三种时钟类型，以及对应的duration和time_point
    /*std::chrono::system_clock s;          // 系统时钟（与现实时间对应）
    std::chrono::steady_clock st;         // 稳定时钟（不会回退，适合计时）
    std::chrono::high_resolution_clock h; // 高精度时钟（精度最高）

    std::chrono::system_clock::duration sd;          // system_clock的时间间隔类型
    std::chrono::steady_clock::duration std;         // steady_clock的时间间隔类型
    std::chrono::high_resolution_clock::duration hd; // high_resolution_clock的时间间隔类型

    std::chrono::system_clock::time_point stp;   // system_clock的时间点
    std::chrono::steady_clock::time_point sttp;  // steady_clock的时间点
    std::chrono::high_resolution_clock::time_point hdtp; // high_resolution_clock的时间点
    */

    // 获取当前时间点（从系统时钟）
    auto tp = std::chrono::system_clock::now();

    // 获取从1970年1月1日（时间纪元）到现在的毫秒数
    auto md = std::chrono::duration_cast<std::chrono::milliseconds>(tp.time_since_epoch());

    // 取出当前时间中的“毫秒部分”（0~999）
    long ms = md.count() % 1000;

    // 将chrono时间转换为C风格时间（time_t）
    time_t now = std::chrono::system_clock::to_time_t(tp);

    // 转换为本地时间结构体
    tm *info = localtime(&now);//tm* localtime(const time_t* timep);前面有

    // 用于存储格式化后的时间字符串
    char timefmt[128] = { 0 };

    // 格式化输出：年-月-日 时:分:秒 毫秒
    sprintf(timefmt, "%d-%d-%d %d:%d:%d %d",
            info->tm_year + 1900,
            info->tm_mon + 1,
            info->tm_mday,
            info->tm_hour,
            info->tm_min,
            info->tm_sec,
            ms);

    // 输出最终时间
    std::cout << timefmt << std::endl;
}
```

📌 tm结构体长这样：

```cpp
struct tm {
int tm_year; // 年（从1900开始）
int tm_mon;  // 月（0-11）
int tm_mday; // 日（1-31）
int tm_hour; // 时
int tm_min;  // 分
int tm_sec;  // 秒
};
```

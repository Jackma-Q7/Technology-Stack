## 时间点time_point
&emsp;&emsp;time_point表示时间点，在前面提到的公式，将时间点加减一个时间间隔还是一个时间点，可以通过clock将时间点换算成具体时间

```cpp
template<class Clock,class Duration = typename Clock::duration>class time_point;

std::chrono::time_point
```

```cpp
#include <chrono>
#include <iostream>
int main()
{
    std::chrono::system_clock::time_point t;
    std::chrono::steady_clock::time_point t1;

    auto t1 = std::chrono::system_clock::now();
}
```

**time_point 需要两个东西：**

+  用哪个时钟（Clock） 
+  用什么单位表示时间（Duration）

✅ 1️⃣ `class Clock`

👉 表示“时钟类型”

常见的有： 决定“时间从哪里来”  

```cpp
std::chrono::system_clock
std::chrono::steady_clock
std::chrono::high_resolution_clock
```

✅ 2️⃣ `class Duration`

👉 表示“时间单位类型”

比如： 决定“时间精度是多少”  

```plain
std::chrono::seconds
std::chrono::milliseconds
std::chrono::nanoseconds
```

**默认参数（关键！）** 如果你不写 Duration，就用 Clock 自带的 duration  

🧠 举个例子

```cpp
std::chrono::time_point<std::chrono::system_clock> t;
```

👉 实际等价于：

```cpp
std::chrono::time_point<
    std::chrono::system_clock,
    std::chrono::system_clock::duration
> t;
```
示例代码
```cpp
#include <iostream>
#include <chrono>
#include <ctime>

int main()
{
    // 1️⃣ 获取当前时间点（time_point）
    std::chrono::system_clock::time_point now = std::chrono::system_clock::now();

    // 2️⃣ 定义一个时间间隔（duration）
    std::chrono::seconds dur(10); // 10秒

    // 3️⃣ 时间点 + 时间间隔 = 新的时间点
    std::chrono::system_clock::time_point future = now + dur;

    // 4️⃣ 时间点 - 时间点 = 时间间隔
    std::chrono::duration<double> diff = future - now;

    std::cout << "间隔秒数: " << diff.count() << " 秒" << std::endl;

    // 5️⃣ 把 time_point 转换为 C 风格时间（可读时间）
    std::time_t now_c = std::chrono::system_clock::to_time_t(now);
    std::time_t future_c = std::chrono::system_clock::to_time_t(future);

    std::cout << "当前时间: " << std::ctime(&now_c);
    std::cout << "未来时间: " << std::ctime(&future_c);

    return 0;
}
#打印结果
间隔秒数: 10 秒
当前时间: Wed Mar 20 15:30:45 2025
未来时间: Wed Mar 20 15:30:55 2025
```
now → 当前时间点
dur → 10秒
future = now + dur → 未来10秒的时间点
future - now → 得到时间间隔（10秒）
to_time_t → 转换成人类能读懂的时间

## 问题 1： template<>class A给我讲下这个语法  
🔥 一句话先记住

```cpp
template<> class A<类型> { ... };
```

👉 **这是“模板的特化版本”——针对某个具体类型写一个专门实现**

🧠 一、先看普通模板

```cpp
template<typename T>
class A
{
public:
    void print()
    {
        std::cout << "通用版本" << std::endl;
    }
};
```

👉 这个是：  
👉 **通用模板（泛型）**

🔥 二、template<> 是什么？

```cpp
template<>
class A<int>
{
public:
    void print()
    {
        std::cout << "int 特化版本" << std::endl;
    }
};
```

✅ 含义

👉 当你写：

```cpp
A<int> a;
```

👉 就不会用通用模板，而是用：

```cpp
A<int> 的专门版本
```

🧪 三、完整示例

```cpp
#include <iostream>
using namespace std;

// 通用模板
template<typename T>
class A
{
public:
    void print()
    {
        cout << "通用版本" << endl;
    }
};

// 特化版本（只针对 int）
template<>
class A<int>
{
public:
    void print()
    {
        cout << "int 特化版本" << endl;
    }
};

int main()
{
    A<double> a1;
    a1.print();   // 通用版本

    A<int> a2;
    a2.print();   // int 特化版本
}
```

🔥 四、你问的重点：`template<>`

👉 它表示：

👉**我不再是模板定义了，我是在写一个‘特例版本’”**

🧠 五、类比理解（很好用）

👉 就像：

```cpp
A<T>       → 通用规则
A<int>     → 特殊规则（单独处理）
```

🔥 六、为什么要用特化？

👉 因为：

👉 有些类型需要特殊处理

📌 举个实际例子

比如：

```cpp
template<typename T>
void print(T x)
{
    cout << x << endl;
}
```

👉 但是如果是：

```cpp
char*   // 字符串
```

👉 你可能想：

```cpp
打印字符串内容，而不是地址
```

👉 就可以用特化

🚨 七、注意一个点（容易混）

你写的是：

```cpp
template<> 
class A
```

👉 ❌ 这是不完整的！

必须写成：

```cpp
template<> 
class A<int>
```

👉 因为你要说明：  
👉 **特化的是哪个类型**

🎯 八、总结（记这个）

**template<> 表示“模板特化”，** 就是为某个具体类型写一个专门版本，  **替代通用模板实现**

## duration_cast
👉  “会丢精度的转换，必须用 `duration_cast`”   高 → 低（ 毫秒 → 秒  要 cast）  

duration_cast可以转化不同类型的时长

在源duration能准确地为目标duration所整除的场合（例如小时到分钟），无需duration_cast

整数时长间转型为浮点时长能隐式进行，无需 duration_cast

```cpp
#include <chrono>
#include <iostream>
#include <thread>
int main()
{
    auto t1 = std::chrono::steady_clock::now();
    std::this_thread::sleep_for(std::chrono::seconds(1));
    auto t2 = std::chrono::steady_clock::now();

    std::chrono::duration<double, std::milli> d = t2 - t1;
    //std::chrono::duration<long long, std::milli>d1 = 
        //std::chrono::duration_cast<std::chrono::duration<long long, std::milli>>(t2 - t1);
    std::chrono::duration<long long, std::milli> d1 = 
    std::chrono::duration_cast<std::chrono::milliseconds>(t2 - t1);
    //本质就是：std::chrono::duration<long long, std::milli>
    std::chrono::minutes m(10);
    std::chrono::seconds s = m;
    std::chrono::milliseconds ms = m;
    std::chrono::seconds s1 = std::chrono::duration_cast<std::chrono::seconds>(ms);
    //600000 ms → 600 s         duration_cast
}
```

第一种写法（浮点毫秒）

```cpp
std::chrono::duration<double, std::milli> d = t2 - t1;
```

 把时间差转换成：   毫秒 + 浮点数  

 1000.523 ms   精度高（有小数）  

 第二种写法（整数毫秒）  

```cpp
std::chrono::duration<long long, std::milli> d1 =
    std::chrono::duration_cast<std::chrono::milliseconds>(t2 - t1);
```

转成：   毫秒 + 整数  

1000 ms  小数被截断 ❗

为什么要 duration_cast？  

纳秒 → 毫秒（会丢精度）  ，所以必须显式转换

**chrono里很多都是这种“别名”：**

```cpp
seconds       = duration<long long, ratio<1>>
milliseconds  = duration<long long, ratio<1,1000>>
minutes       = duration<long long, ratio<60>>
```

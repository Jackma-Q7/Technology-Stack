## shared_ptr的线程安全
&emsp;&emsp;多个线程能在 shared_ptr 的不同实例上调用所有成员函数（包含复制构造函数与赋值函数）而不用附加同步，即使这些实例是副本，且共享同一对象的所有权。若多个执行线程访问同一 shared_ptr 而不同步，且任一线程使用 shared_ptr 的非 const 成员函数，则将出现数据竞争

根据上面的描述可以归纳为以下几点:   

1.一个shared_ptr对象可以被多个线程同时读

2.两个shared_ptr对象实体可以被两个线程同时读写，即使它们管理的是同一个对象

3.多个线程读写同一个shared_ptr对象实体，那么需要加琐

```cpp
#include <memory>
#include <thread>
#include <mutex>

std::shared_ptr<int> gInt;
std::mutex gMutex;
void read()
{
    std::shared_ptr<int> localPtr;

    {
        std::lock_guard<std::mutex> lock(gMutex);
        //对于gInt来说是读操作
        localPtr = gInt;
    }// 锁在这里释放

    do(localPtr);
}

void write()
{
    std::shared_ptr<int> newPtr = std::make_shared<int>(18);

    {
        std::lock_guard<std::mutex> lock(gMutex);
        //对于gInt来说是写操作
        gInt = newPtr;
    }

    do(newPtr);

}
```

问## 题1：std::mutex gMutex;是干嘛的  ？

std::lock_guard<std::mutex> lock(gMutex);

| 操作       | 含义                     |
|------------|--------------------------|
| 加锁       | 当前线程“占用”gMutex     |
| 其他线程   | 必须等待                 |
| 出作用域   | 自动解锁                 |

用 mutex 保证安全地拿到指针，用 shared_ptr 保证对象在使用时不会被释放（避免野指针）

```cpp
#include <iostream>
#include <memory>
#include <thread>
#include <mutex>
#include <vector>
#include <chrono>

std::shared_ptr<int> gData = std::make_shared<int>(0);
std::mutex gMutex;

// 读线程
void reader(int id)
{
    for (int i = 0; i < 5; i++)
    {
        std::shared_ptr<int> localPtr;

        {
            std::lock_guard<std::mutex> lock(gMutex);
            localPtr = gData;   // 安全拷贝 shared_ptr
        } // 这里自动解锁

        if (localPtr)
        {
            std::cout << "Reader " << id
                      << " read value = " << *localPtr << std::endl;
        }

        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
}

// 写线程
void writer(int id)
{
    for (int i = 0; i < 5; i++)
    {
        std::shared_ptr<int> newPtr = std::make_shared<int>(i + 1);

        {
            std::lock_guard<std::mutex> lock(gMutex);
            gData = newPtr;   // 安全修改全局 shared_ptr
            std::cout << "Writer " << id
                      << " write value = " << *gData << std::endl;
        } // 这里自动解锁

        std::this_thread::sleep_for(std::chrono::milliseconds(150));
    }
}

int main()
{
    std::vector<std::thread> threads;

    threads.emplace_back(reader, 1);
    threads.emplace_back(reader, 2);
    threads.emplace_back(writer, 1);

    for (auto& t : threads)
    {
        t.join();
    }

    return 0;
}
```

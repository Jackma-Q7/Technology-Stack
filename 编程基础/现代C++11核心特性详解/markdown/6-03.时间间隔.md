## 时间间隔Duration
**比率(std::ratio)**

```cpp
template<std::intmax_t Num, std::intmax_t Denom = 1 > class ratio
```

&emsp;&emsp;std::ratio代表一个比率，Num是分子，Denom是分母， Denom 不可为零且不可等于最负的值。代表的数值约分分子和分母到最简

```cpp
#include <iostream>
#include <ratio>

int main()
{
    // 表示 2/4
    typedef std::ratio<2, 4> r;

    // ratio 会自动约分！
    std::cout << r::num << "/" << r::den << std::endl;

    return 0;
}
```

Duration

```cpp
template <class Rep, class Period = ratio<1> > class duration
```

&emsp;&emsp;它代表的是一个时间间隔，Period就是精度(比如秒ration<1>，毫秒ration<1,1000>)，**它支持算术运算符，支持比较运算符**

**三种clock的精度**	

&emsp;&emsp;在每个clock类型都一个period的成员变量,它是一个ratio类型(比率),以一秒为分子,精度为分母,可以通过打印period的den成员值来确定clock的精度

```cpp
//环境 win10+vs2017
std::cout << system_clock::period::den << std::endl;//10000000(100纳秒)
std::cout << high_resolution_clock::period::den << std::endl;//1000000000(1纳秒）
std::cout << steady_clock::period::den << std::endl;//1000000000(1纳秒）
```

不同平台的结果不同

```cpp
#include <chrono>
#include <iostream>

int main()
{
    std::cout << "system_clock "<< std::chrono::system_clock::period::den << std::endl;
    std::cout << "steady_clock " << std::chrono::steady_clock::period::den << std::endl;

    //精度 100纳秒
    std::cout << "system_clock " << (double)std::chrono::system_clock::period::num/
        (double)std::chrono::system_clock::period::den << std::endl;
    //精度 纳秒
    std::cout << "steady_clock " << (double)std::chrono::steady_clock::period::num / 
        (double)std::chrono::steady_clock::period::den << std::endl;

}
```

**使用基本的时间单元**

&emsp;&emsp;在chrono库中，预定义了六种时间元:hours ,minutes ,seconds ,milliseconds ,microseconds ,nanoseconds ,可以拿来直接使用:

```cpp
//using seconds = duration<long long>
seconds s(1);//代表1秒钟

//using minutes = duration<int, ratio<60>>
minutes m1(1); //代表1分钟

//using milliseconds = duration<long long, milli>;
milliseconds ms(10); //代表10毫秒
milliseconds ms(1000); //代表1000毫秒即1秒
```

**定义有意义的时间单元**

&emsp;&emsp;在duration中预定义的时，分，秒等，本质上是类型别名，也可以通过这种方式定义在业务系统中有意义的时间单元，比如，在音视频系统，编码端会设置采集或编码的帧率，比如设置为25帧，可以理解成每40ms产生一帧数据(采集或编码),那么通过duration定义40ms的时间单元

```cpp
//在25帧的情况下，代表每帧的时间隔即为40ms(ration<1,25>)(1/25)
typedef std::chrono::duration<long,std::ratio<1,25>> FrameRate;
//代表一帧的时间间隔
FrameRate(1)
```

```cpp
#include <chrono>
#include <iostream>
#include <thread>
int main()
{
    std::chrono::system_clock::duration d;

}
```

## 问题1：template<std::intmax_t Num, std::intmax_t Denom = 1 > class ratio这是什么语法？

1.完整语法逐行解析  

```cpp
// std::ratio 的标准定义简化版
template<
std::intmax_t Num,    // 第1个非类型模板参数：分子
std::intmax_t Denom = 1  // 第2个非类型模板参数：分母（默认值=1）
>
class ratio;
```

2.核心关键词解释  

| **语法片段** | **含义** |
| --- | --- |
| ` template<...> ` |  模板声明关键字，表示这是一个  **模板类** |
| ` std::intmax_t  ` |  C++ 标准的  **最大宽度有符号整数类型** （比 int/long 更大）   |
| ` Num  ` |  模板参数名：代表  **分数的分子** |
| ` Denom = 1  ` |  模板参数名：代表  **分数的分母** ，  **带默认值** （不传则自动 = 1）   |
| ` class ratio  ` |  定义一个名为   ` ratio  ` 的  **模板类** |


 2. 这是什么模板？  

 它是   **非类型模板参数（Non-type Template Parameter）**

+  普通模板（如   ` vector<T>  ` ）传的是  **类型** （  ` int  ` /  ` string  ` ）  
+  这个模板传的是  **编译期常量值** （整数、地址等）  

` std::ratio  `  要求：  **所有参数必须是编译期就能确定的整数** ，不能是运行时变量。  

` class ratio;  ` 只是**声明**，真正的 ` std::ratio  ` 内部有大量**编译期计算逻辑、静态常量、类型别名**，它是一个**功能完整的模板类**。  所以用直接 `using   seconds  =   std ::  ratio <1>;`就可以

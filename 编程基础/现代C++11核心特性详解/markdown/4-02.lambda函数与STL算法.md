## STL与lambda
&emsp;&emsp;lambda函数是一种语法糖，就地编写函数代码后，编译器会生成一个函数对象。其目的就是为来简化代码。这在与STL结合使用时体现的很明显，它具有函数对象的优点，编写也十分便捷

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
void PrintValue(int i)
{
    if (i < 6)
    {
        std::cout << i << std::endl;
    }
}

class CPrintValue
{
public:
    CPrintValue(int i) :_value(i)
    {

    }

    void operator()(int i)
    {
        if (i < _value)
        {
            std::cout << i << std::endl;
        }
    }
private:
    int _value;
};

void check(int iCheck)
{
    std::vector<int> vecAllInfo = { 1,2,3,4,5,10,100 };
    //std::for_each(vecAllInfo.begin(), vecAllInfo.end(), PrintValue);

    /*CPrintValue t(6);
    std::for_each(vecAllInfo.begin(), vecAllInfo.end(), t);
    CPrintValue t1(100);
    std::for_each(vecAllInfo.begin(), vecAllInfo.end(), t1);*/

    std::for_each(vecAllInfo.begin(), vecAllInfo.end(), [=](int i) {
        if (i < iCheck)
        {
            std::cout << i << std::endl;
        }
    });
}

int main()
{
    check(100);
}
```

这个类是一个 **函数对象（仿函数）**，你可以这样用：

```cpp
CPrintValue obj(10);
obj(5);   // 相当于 obj.operator()(5)
```

这里：

+ `obj(5)` 里的 `5`
+  就是传给 `operator()(int i)` 里的 `i`

lambda（最推荐🔥）

```cpp
std::for_each(vec.begin(), vec.end(), [=](int i) {
    if (i < iCheck)
    {
        std::cout << i << std::endl;
    }
});
```

👉 关键点：

+ `[=]` 👉 捕获外部变量（这里是 `iCheck`） 
[=] 的含义是：把外部用到的变量，按“值拷贝”进 lambda 内部
+ `(int i)` 👉 当前遍历到的元素 
+  逻辑和前两种一样 

👉 特点：

+  写法最简单 ✅ 
+  不用写类 
+  不用单独写函数

## 问题1：STL算法是什么。这和STL有什么关系？
什么是 STL？

👉 **C++ Standard Template Library** 是一整套工具库

主要包含三大块：

1. **容器（container）**  
👉 `vector / list / map`
2. **算法（algorithm）**  
👉 `for_each / sort / find`
3. **迭代器（iterator）**  
👉 用来把“容器”和“算法”连接起来

什么是 STL算法？

👉 **STL算法 = 一堆已经写好的通用函数**

比如：

```cpp
std::sort(...)
std::for_each(...)
std::find(...)
```

它们的特点：

+  不关心数据存在哪（vector？list？） 
+  只要你给它“迭代器”就能用 

🔹它们之间的关系（重点🔥）

👉 一句话：

**STL = 容器 + 算法 + 迭代器**

关系是这样👇

```cpp
容器（装数据）
   ↓
迭代器（拿数据）
   ↓
算法（处理数据）
```

🔹用你代码举例

```cpp
std::vector<int> vec = {1,2,3,4};
std::for_each(vec.begin(), vec.end(), func);
```

对应关系：

+ `vector` 👉 容器 
+ `begin()/end()` 👉 迭代器 
+ `for_each` 👉 算法 

👉 算法通过“迭代器”去操作“容器”

🔹核心思想（很重要）

👉 **算法和数据分离**

+  算法：只负责“怎么做” 
+  容器：只负责“存什么” 

好处：

+  可以复用 
+  非常灵活 

🔹一句话总结

👉 **STL算法就是操作容器数据的通用函数，它通过迭代器和容器解耦**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
std::vector<int> vecValue = { 1,2,3,4,5,6 };

void Print()
{
    std::for_each(vecValue.begin(), vecValue.end(), [=] (int i){
        std::cout << " "<<i << " ";
    });
}
void AddValue(int Value)
{
    std::for_each(vecValue.begin(), vecValue.end(), std::bind2nd(std::plus<int>(), Value));
    Print();

    std::transform(vecValue.begin(), vecValue.end(), vecValue.begin(), std::bind2nd(std::plus<int>(), Value));
    Print();

    std::for_each(vecValue.begin(), vecValue.end(), [=](int &i) {
        i += Value;
    });

    Print();
}

int main()
{
    AddValue(10);
}
```

第一段

```cpp
std::for_each(vecValue.begin(), vecValue.end(), std::bind2nd(std::plus<int>(), Value));
Print();
```

这句很多初学者会以为“加完了”，但其实 **没改容器**。

原因是：

+ `std::plus<int>()` 是一个“加法函数对象” 
+ `std::bind2nd(..., Value)` 把第二个参数绑定成 `Value`
+  于是它会计算：`元素 + Value`

但 `for_each` 只是 **调用这个计算**，并不会把结果写回 `vecValue`

所以这段相当于：

+  算了 
+  但没存起来 

因此第一次 `Print()` 打印的还是原来的：

```cpp
1 2 3 4 5 6
```

第二段

```cpp
std::transform(vecValue.begin(), vecValue.end(), vecValue.begin(), std::bind2nd(std::plus<int>(), Value));
Print();
```

这次就不一样了。

`transform` 的作用是：

👉 把处理后的结果写到目标位置

这里参数意思是：

+  读数据：`vecValue.begin()` 到 `vecValue.end()`
+  写回位置：`vecValue.begin()`

所以每个元素都会变成：

```cpp
原值 + 10
```

变完后 `vecValue` 就是：

```cpp
11 12 13 14 15 16
```

所以第二次 `Print()` 打印的是这个。

第三段

```cpp
std::for_each(vecValue.begin(), vecValue.end(), [=](int &i) {
    i += Value;
});
```

这段也会修改原数据。

关键在这里：

```cpp
(int &i)
```

这里是 **引用传递**，`i` 直接引用容器里的元素本身。  
所以执行：

```cpp
i += Value;
```

就是真的把容器里的值改了。

因为前一步已经变成了：

```cpp
11 12 13 14 15 16
```

再加 10 后，就变成：

```cpp
21 22 23 24 25 26
```

所以第三次 `Print()` 打印这个结果。

最终输出顺序

所以整个程序输出大概是：

```plain
1 2 3 4 5 6
11 12 13 14 15 16
21 22 23 24 25 26
```

这段代码最想让你学会的点

你重点记这三个区别：

1. `for_each`

只是“对每个元素做点事”，不一定修改容器。

2. `transform`

是“把处理结果写回去”或写到新容器里。

3. lambda 参数是值还是引用，很重要

+ `int i`：拿副本，改了没用 
+ `int &i`：拿原对象，改了就会影响容器

## 问题2： 为什么程序就知道int &i是传入的for_each每次的次呢？  
🔹先看 `for_each` 本质做了什么

你可以把它理解成一个“展开版循环”：

```cpp
for (auto it = vecValue.begin(); it != vecValue.end(); ++it)
{
    func(*it);   // 👈 关键！
}
```

👉 重点就在这句：

```cpp
func(*it);
```

+ `*it` = 当前元素 
+  每次循环，把当前元素传进去 

🔹套到你的代码

```cpp
std::for_each(vecValue.begin(), vecValue.end(), 
    [=](int &i) { i += Value; });
```

等价于：

```cpp
for (auto it = vecValue.begin(); it != vecValue.end(); ++it)
{
    auto &i = *it;   // 👈 这里匹配到了 int& i
    i += Value;
}
```

🔹为什么能“自动匹配 int &i”？

👉 因为这一句：

```cpp
func(*it);
```

情况1：你写的是

```cpp
(int i)
```

那就是：

```plain
int i = *it;  // 拷贝一份
```

情况2：你写的是

```plain
(int &i)
```

那就是：

```plain
int &i = *it;  // 引用绑定到原数据
```

## lambda小结
lambda是语法糖，被编译器转换成了函数对象

lambda函数实现的功能要简单，代码要短小  
出于易维护的考虑。lambda的捕获列表应用按值捕获

```cpp
auto adder = [n](int x){return n+x;};

被转换为

struct lambda_xxxx
{
lambda_xxxx(int n):n_(n){}
auto operator()(int x) const
{
    return n_+x;？
}

private:
int n_;
};

auto adder = lambda_xxxx(n);
```

👉 **n 是在“创建 lambda 时”传进去的**  
👉 **x 是在“调用 lambda 时”传进去的**

🟢 第一步：创建对象（传 n）

```cpp
auto adder = [n](int x){ return n + x; };
```

等价于：

```cpp
lambda_xxxx adder(n);  // 👈 这里传 n
```

👉 这一步做的是：

+  把 `n` 存进对象里的 `n_`

🟢 第二步：调用对象（传 x）

```cpp
adder(5);
```

等价于：

```cpp
adder.operator()(5);  // 👈 这里传 x
```

👉 这一步：

+  把 `5` 传给 `x`
+  用之前存好的 `n_` 一起计算 

🔹完整流程串起来

```cpp
int n = 10;

auto adder = [n](int x){ return n + x; };
// 👉 lambda_xxxx adder(10);

adder(5);
// 👉 adder.operator()(5);
```

内部发生的是：

```cpp
return n_ + x;  // 10 + 5
```

## 问题3： 在C++中函数都属于对象？
不管是函数，成员函数，函数指针，lambda  

🔹先给你结论（很重要）

👉 **不是所有函数都是对象**  
👉 **但很多“能调用的东西”可以被当成对象用**

🔹1️⃣ 普通函数（❌ 不是对象）

```cpp
void func(int x) {}
```

👉 这是：

+  一段代码（在代码区） 
+  不是对象 
+  没有“成员”“状态” 

✔ 但它可以被“当成可调用对象使用”

🔹2️⃣ 函数指针（✅ 是对象）

```cpp
void (*p)(int) = func;
```

👉 这是：

+  一个变量（在栈/全局区） 
+  里面存的是函数地址 

✔ 所以它是对象（变量）

🔹3️⃣ 仿函数（函数对象）（✅ 是对象）

```cpp
class A {
public:
void operator()(int x) {}
};
```

```plain
A a;
a(10);
```

👉 这是：

+  类对象 
+  有数据成员（可以有状态） 

✔ 标准的“对象”

🔹4️⃣ lambda（✅ 本质是对象）

```cpp
auto f = [](int x){ return x + 1; };
```

👉 本质会变成：

```cpp
class __Lambda {
public:
    int operator()(int x) const { return x + 1; }
};
```

✔ 所以：

👉 **lambda 本质就是一个匿名类对象**

🔹5️⃣ 成员函数（❌ 不是对象）

```cpp
class A {
public:
    void func() {}
};
```

👉 成员函数：

+  也是代码 
+  不是对象 

但可以有：

```cpp
void (A::*p)() = &A::func;//&A::func：取类成员函数的地址//A::：指针只能指向 A 类里的成员函数
```

👉 这个“成员函数指针”才是对象

🔹统一一个概念（核心🔥）

👉 C++里有个更准确的词：

👉 **“可调用对象（Callable）”**

包括：

+  普通函数 ✅ 
+  函数指针 ✅ 
+  仿函数 ✅ 
+  lambda ✅ 
+  bind结果 ✅ 

🔹总结表（一定要区分清楚）

| 类型 | 是对象吗 | 能调用吗 |
| --- | --- | --- |
| 普通函数 | ❌ | ✅ |
| 函数指针 | ✅ | ✅ |
| 成员函数 | ❌ | ✅ |
| 仿函数 | ✅ | ✅ |
| lambda | ✅ | ✅ |


🔹一句话总结（面试级🔥）

👉 **C++里不是所有函数都是对象，但所有“可调用对象”都可以像函数一样用**

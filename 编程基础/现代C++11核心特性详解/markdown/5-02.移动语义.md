## 移动语义
&emsp;&emsp;移动语义就是从给定对象”窃取”资源而不是拷贝资源，源对象不再拥有资源，资源的所有权已经归属新创建的对象

&emsp;&emsp;在有拥有内存资源的对象中，通过复制语义(深拷贝)来转移内存，将源对象赋值给目标对象，源对象中资源很可能是不需要再保留的，这时直接将源对象中的资源转移给目标对象(浅拷贝，只移动指针)，就更贴切。但是使用左值引用来实现有两个限制：

1. 为了满足所有的表示移动的场景，它必须是一个构造函数，并且形参需为const &(为了能引用临时对象这样的右值)，为了与其它构造函数作区分，形参个数需不同(显然是没有这样的语法的)
2. 对const引用的形参，在函数中并不能改变的它

引入右值引用就是来实现移动语义的，解决实现上的限制，

```cpp
#include <iostream>
#include <cstring>
#include <string>

class CPointTest
{
public:
    // 默认构造函数
    CPointTest()
    {
        m_size = 1024;
        m_pInts = new int[1024];
        memset(m_pInts, 0, 1024 * sizeof(int));
    }

    // 有参构造函数
    CPointTest(int* pData, int size) : m_pInts(pData), m_size(size)
    {

    }

    // 析构函数
    ~CPointTest()
    {
        std::cout << "~CPointTest()" << std::endl;
        delete[] m_pInts;
        m_pInts = nullptr;
    }

    // 拷贝构造函数：深拷贝
    CPointTest(const CPointTest& t)
    {
        std::cout << "CPointTest(const CPointTest& t)" << std::endl;
        m_size = t.m_size;
        m_pInts = new int[m_size];
        memcpy(m_pInts, t.m_pInts, m_size * sizeof(int));
    }

    // 移动构造函数：偷资源
    CPointTest(CPointTest&& t) noexcept
    {
        std::cout << "CPointTest(CPointTest&& t)" << std::endl;
        m_size = t.m_size;
        m_pInts = t.m_pInts;

        t.m_pInts = nullptr;
        t.m_size = 0;
    }
//noexcept告诉编译器和STL：这个函数不会抛异常，从而允许使用更高效的移动操作
    // 移动赋值运算符：先释放自己原来的资源，再偷别人的资源
    CPointTest& operator=(CPointTest&& t) noexcept
    {
        std::cout << "CPointTest& operator=(CPointTest&& t)" << std::endl;

        if (this != &t)
        {
            delete[] m_pInts;

            m_size = t.m_size;
            m_pInts = t.m_pInts;

            t.m_pInts = nullptr;
            t.m_size = 0;
        }

        return *this;
    }

    // 拷贝赋值运算符：深拷贝
    CPointTest& operator=(const CPointTest& t)
    {
        std::cout << "CPointTest& operator=(const CPointTest& t)" << std::endl;

        if (this != &t)
        {
            delete[] m_pInts;

            m_size = t.m_size;
            m_pInts = new int[m_size];
            memcpy(m_pInts, t.m_pInts, m_size * sizeof(int));
        }

        return *this;
    }

private:
    int* m_pInts = nullptr;
    int m_size = 0;
};

CPointTest GetPointTest()
{
    CPointTest t;
    // 返回局部对象，可能触发移动构造，也可能被编译器优化掉
    return t;
}

CPointTest f()
{
    CPointTest t;
    return t;
}

int main()
{
    // 用 f() 返回的临时对象初始化 t1
    // 可能触发移动构造，也可能被返回值优化 RVO 省略
    CPointTest t1(f());

    CPointTest t2;

    // 通过拷贝构造函数创建 t3
    CPointTest t3 = t2;

    // 拷贝赋值
    t3 = t1;

    // 移动赋值，CPointTest() 是临时对象，属于右值
    t3 = CPointTest();

    std::string str = "123";

    std::cout << str.c_str() << std::endl;

    // std::move(str) 把 str 转成右值，调用 string 的移动构造
    std::string str1(std::move(str));

    // str 被移动后，内容不保证还在，一般会变成空字符串
    std::cout << str.c_str() << std::endl;
    std::cout << str1.c_str() << std::endl;

    std::system("pause");
}
```

👉 **自己实现一个“带堆内存的类”，并同时支持拷贝（深拷贝）+ 移动（偷资源）**

🧠第一步：这个类本质是什么？

```cpp
int* m_pInts;
int m_size;
```

👉 本质：**类里面管理了一块堆内存（new出来的数组）**

所以问题来了：

❗ 默认拷贝 = 只拷贝指针（浅拷贝）  
❗ 会导致：两个对象指向同一块内存 → 重复 delete → 崩溃

👉 所以你必须自己写：

+  拷贝构造（深拷贝） 
+  拷贝赋值（深拷贝） 
+  移动构造（偷资源） 
+  移动赋值（偷资源） 

🧱第二步：构造 & 析构

```cpp
CPointTest()
{
    m_pInts = new int[1024];
}
```

👉 创建资源

```cpp
~CPointTest()
{
    delete[] m_pInts;
}
```

👉 释放资源

✔️ 这是典型 **RAII**

🔁第三步：拷贝（深拷贝）

**<font style="color:#DF2A3F;">拷贝构造</font>**

```cpp
CPointTest(const CPointTest& t)
```

👉 做了三件事：

1.  分配新内存 
2.  拷贝数据 
3.  不共享指针 

✔️ 每个对象有自己的一份数据

**<font style="color:#DF2A3F;">拷贝赋值</font>**

```cpp
t3 = t1;
```

调用：

```cpp
operator=(const CPointTest&)
```

流程：

1.  先 delete 自己的旧内存 
2.  再 new 新内存 
3.  再 memcpy 

⚡第四步：移动（重点！！）

核心思想：

👉 **不拷贝，直接抢资源（指针）**

**<font style="color:#DF2A3F;">移动构造</font>**

```cpp
CPointTest(CPointTest&& t)
```

做了：

```cpp
m_pInts = t.m_pInts;
t.m_pInts = nullptr;
```

👉 含义：

+  我直接接管你的内存 
+  你变空（防止析构炸） 

**<font style="color:#DF2A3F;">移动赋值</font>**

```cpp
t3 = CPointTest();
```

流程：

1.  释放自己原来的内存 
2.  拿走临时对象的指针 
3.  把对方置空 

🧪第五步：main 运行逻辑

①

```cpp
CPointTest t1(f());
```

👉 `f()` 返回临时对象（右值）

可能发生：

+  移动构造 
+  或 RVO（直接省略构造） 

②

```cpp
CPointTest t3 = t2;
```

👉 调用：拷贝构造

③

```cpp
t3 = t1;
```

👉 左值 → 拷贝赋值

④（重点）

```cpp
t3 = CPointTest();
```

👉 右值 → 移动赋值

🧵第六步：string 那段

```cpp
std::string str1(std::move(str));
```

👉 本质：

+ `std::move` = 强制把左值变成右值 
+  调用 string 的移动构造 

结果：

```cpp
str → 被搬空（一般变 ""）
str1 → 拿到数据
```

这段代码其实就讲清楚一件事：

**类里一旦有“堆资源”，就必须自己控制拷贝和移动**

🚀一句话总结（重点）

👉 **拷贝 = 复制数据（慢但安全）  
****👉**** 移动 = 偷指针（快但要置空）**

## 问题1：拷贝构造和拷贝赋值作用是没区别的对吗？  
| 写法 | 调用 |
| --- | --- |
| `A a = b;` | 拷贝构造 |
| `A a(b);` | 拷贝构造 |
| `a = b;` | 拷贝赋值 |


+ **拷贝构造 = “出生”**
+ **拷贝赋值 = “换灵魂”**

## 问题2： 对于是拷贝还是移动，最关键的就是传入的参数是左值引用还是右值引用 ？
 👉 **是否调用拷贝还是移动，关键不是“你写的是 & 还是 &&”，而是：传入的是左值还是右值**

函数只是“提供两种版本”

```cpp
CPointTest(const CPointTest& t); // 拷贝
CPointTest(CPointTest&& t);      // 移动
```

👉 这只是告诉编译器：

+  如果你给我左值 → 用这个 
+  如果你给我右值 → 用那个

🔹左值 → 走拷贝

```cpp
CPointTest t1;
CPointTest t2 = t1; // t1 是左值
```

👉 调用：拷贝构造

🔹右值 → 走移动

```cpp
CPointTest t2 = CPointTest();
```

👉 临时对象 = 右值  
👉 调用：移动构造

🔹std::move 强转右值（重点）

```cpp
CPointTest t2 = std::move(t1);
```

👉 虽然 t1 是左值变量  
👉 但被 **强制变成右值**

👉 调用：移动构造

## 问题3： 有点分不清对象的左值右值  
🔹情况1

```cpp
CPointTest t1;
```

👉 `t1` 是：

✔️ 有名字  
✔️ 能 `&t1`

👉 ✅ 左值

🔹情况2

```cpp
CPointTest();
```

👉 临时对象：

❌ 没名字  
❌ 一会就销毁

👉 ✅ 右值

🔹情况3（关键）

```cpp
f()
```

👉 返回一个临时对象

👉 ✅ 右值

⚠️最容易错的地方（重点！）

❗右值引用变量，本身是左值！

```cpp
CPointTest&& x = CPointTest();
```

👉 `x` 是什么？

👉 **左值！**

因为：

+  有名字 
+  可以 `&x`

如果你这样写：

```cpp
CPointTest t2 = x;
```

👉 ❗调用的是：**拷贝构造**

想走移动？

```cpp
CPointTest t2 = std::move(x);
```

👉 才会调用：移动构造

🧠为什么会这样？

👉 因为：

**表达式是否是左值/右值，和“变量类型”无关，而是看“表达式本身”**

🔥一张总结表（你直接记）

| 写法 | 左值/右值 |
| --- | --- |
| `a` | 左值 |
| `t1` | 左值 |
| `10` | 右值 |
| `a + 1` | 右值 |
| `f()` | 右值 |
| `CPointTest()` | 右值 |
| `x（右值引用变量）` | ❗左值 |
| `std::move(x)` | 右值 |


**🚀一句话终极理解**

👉 **“有没有名字 ≈ 左值；是不是临时 ≈ 右值；但变量一旦有名字，就永远是左值！”**

## 问题4：表达式是否是左值/右值，和“变量类型”无关，而是看“表达式本身”这是什么意思 ？
区分两个东西  

| 概念    | 是什么                  |
| ----- | -------------------- |
| 变量类型  | `int / int& / int&&` |
| 表达式类别 | 左值 / 右值              |

一、变量类型（Type）
```cpp
int a;      // 普通类型
int& b = a; // 左值引用类型
int&& c = 10; // 右值引用类型
```
👉 这些属于：
👉 “变量的类型”

二、表达式类别（Value Category）
```c
a      // 左值
b      // 左值
c      // 左值（重点🔥）
10     // 右值
a + 1  // 右值
```
👉 这些属于：
👉 “表达式的性质”

## 移动构造函数和移动赋值函数
&emsp;&emsp;支持移动语义的对象都需要定义移动构造函数和移动赋值函数，它们的形参都是右值引用，如：

//移动构造函数

`CMoveTest(CMoveTest &&t) noexcept`

//移动赋值函数

`CMoveTest& operator=(CMoveTest&& t) noexcept`

它们有三点要求：

1. 动语义可以将一个对象中的资源移走，而不是赋值，所以它们并不分配内存

2. 移动后的源对象会被销毁(形参是右值引用)，所以内部资源会被置为无效(比如指针会被置为nullptr)

3. 它们都需要声明为noexcept(不能抛异常)

## 编译器生成移动操作
&emsp;&emsp;如果我们在类中没有定义拷贝操作，那么编码器会自动为我们生成默认的拷贝操作，但是对移动操作，编译器是有条件生成的，要满足以下两点

1.类中没有自定义拷贝控制成员(拷贝构造函数，赋值操作，析构函数)

2.它的所有数据成员都能够移动构造或移动赋值

&emsp;&emsp;如果需要移动语义，建议自己定义，不要编译器合成（编译器是能使用拷贝，就不会使用移动，除非对象明确的定义了移动语义）

 👉 **编译器只有在“你完全没碰资源管理”的情况下，才会帮你生成移动操作；一旦你自己接管资源，就必须自己实现移动，否则只会退回拷贝。**

**什么成员不支持移动?**

| 成员类型                | 是否支持移动        | 说明           |
|-------------------------|---------------------|----------------|
| int / double            | ✔（但等于拷贝）     | 没意义         |
| 裸指针                  | ⚠（危险）           | 浅拷贝         |
| std::string / vector    | ✔                   | 真正移动       |
| unique_ptr              | ✔                   | 典型移动       |
| 引用                    | ❌                  | 不能改绑定     |
| const成员               | ❌（赋值不行）      | 限制移动       |
| mutex等同步对象         | ❌                  | 明确禁止       |

## 问题5：
&emsp;&emsp;如果没有定义移动，但是我使用了移动，他会用拷贝这部分吗？给我举个示例  

🔥示例1：没有移动，只能拷贝

```cpp
#include <iostream>

class A
{
public:
    A() {}

    // 只有拷贝构造
    A(const A& )
    {
        std::cout << "拷贝构造" << std::endl;
    }
};

int main()
{
    A a;

    A b = a;              // 左值 → 拷贝
    A c = A();            // 右值 → ❗仍然是拷贝（因为没有移动）
}
```

👉 输出：

```plain
拷贝构造
拷贝构造
```

🔥示例2：加上 std::move 也没用

```cpp
int main()
{
    A a;

    A b = std::move(a);  // 强行变右值
}
```

👉 结果还是：

```plain
拷贝构造
```

👉 因为：

❗ **没有移动构造，move 也没用，只能走拷贝**

🔥示例3：一旦有移动，就会优先用移动

```cpp
#include <iostream>

class A
{
public:
    A() {}

    A(const A& )
    {
        std::cout << "拷贝构造" << std::endl;
    }

    A(A&&)
    {
        std::cout << "移动构造" << std::endl;
    }
};

int main()
{
    A a;

    A b = a;              // 左值 → 拷贝
    A c = A();            // 右值 → 移动
    A d = std::move(a);   // 右值 → 移动
}
```

👉 输出：

```plain
拷贝构造
移动构造
移动构造
```

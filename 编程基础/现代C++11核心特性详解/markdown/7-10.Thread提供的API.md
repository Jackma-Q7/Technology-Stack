## 获取当CPU的核心数
`std::thread::hardware_concurrency();`

&emsp;&emsp;获取硬件支持的并发线程数，可以理解成CPU的核心数，不同OS上实现方式不一样，按标准的描述，该值只是一个hint(提示)，不一定准确。通常要获取CPU核心数，最好调用OS提供API

&emsp;&emsp;线程池的大小往往设置为cpu的核心数，来避免频繁的上下文切换

## this_thread命名空间中的方法
&emsp;&emsp;`this_thread`顾名思义，是指代的当前线程，该命名空间的所有方法都是针对当前线程的

获取线程ID

`std::this_thread::get_id()`

&emsp;&emsp;我们在分析程序的运行状态时，可以通过工具看到程序中线程的运行状态，典型的在linux下可以通过top命令看到线程的运行状态，包括线程cpu占用率等，此时的线程ID就是每个线程唯一标识。通常我们在日志中记入thread id，以便结构工具分析线程的运行情况。

线程休眠

`std::this_thread::sleep_for`

使当前线程休眠一段时间，它的参数是一个时间段

`std::this_thread::sleep_until`

使当前线程休眠到指定时间点，它的参数是一个时间点

```cpp
#include <iostream>
#include <thread>
#include <chrono>

void worker()
{
    // 获取当前线程ID
    std::cout << "Thread ID: " << std::this_thread::get_id() << std::endl;

    // 休眠2秒
    std::cout << "sleep_for 2 seconds...\n";
    std::this_thread::sleep_for(std::chrono::seconds(2));

    // 休眠到指定时间点（再等2秒）
    auto wakeTime = std::chrono::steady_clock::now() + std::chrono::seconds(2);
    std::cout << "sleep_until...\n";
    std::this_thread::sleep_until(wakeTime);

    std::cout << "Thread finished\n";
}

int main()
{
    // 获取CPU核心数（提示值）
    unsigned int cpuNum = std::thread::hardware_concurrency();
    std::cout << "CPU cores (hint): " << cpuNum << std::endl;

    // 创建一个线程
    std::thread t(worker);

    // 主线程ID
    std::cout << "Main Thread ID: " << std::this_thread::get_id() << std::endl;

    t.join();
    return 0;
}
```
输出大概长这样（顺序可能略有不同）
```cpp
CPU cores (hint): 8
Main Thread ID: 12345
Thread ID: 67890
sleep_for 2 seconds...
sleep_until...
Thread finished
```

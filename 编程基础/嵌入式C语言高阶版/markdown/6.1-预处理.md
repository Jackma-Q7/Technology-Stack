# 六、面试常见问题

## 6.1-预处理-#define

```c
Q：用预处理指令 #define 声明一个常数，用以表明 1 年中有多少秒（忽略闰年问题）

#define 宏名 宏体

宏名一般用大写字母表示。

#define SECOND_OF_YEAR (365 * 24 * 3600) UL

L 表示长整型，因为可能 CPU 位数不一样，至少保证为 4 字节。
U 表示无符号。

int a = SECOND_OF_YEAR; // 编译阶段已经处理为常数

需要注意：

1. #define 语法的基本知识：不能以分号结束，括号的使用等。

2. 预处理器会直接替换宏表达式，所以不是在运行时计算，而是在编译前进行文本替换。

3. 这个表达式的结果是 31536000，虽然没有超过 16 位整型范围会溢出，因此要用长整型符号 L，告诉编译器这个常数是长整型数。

4. 如果表达式中用到 UL，表示 unsigned long，也就是无符号长整型。

推荐写法：

#define SECOND_OF_YEAR (365UL * 24UL * 3600UL)

或者：

#define SECOND_OF_YEAR (365 * 24 * 3600UL)

使用示例：

#include <stdio.h>

#define SECOND_OF_YEAR (365UL * 24UL * 3600UL)

int main(void)
{
    unsigned long a = SECOND_OF_YEAR;

    printf("SECOND_OF_YEAR = %lu\n", a);

    return 0;
}

输出结果：

SECOND_OF_YEAR = 31536000
```

```c
#include <stdio.h>

// 嵌入式程序员面试题：下面这个 MIN 宏有哪些问题？

// 原始写法：
#define MIN(A,B) A <= B ? A : B

// 问题1：运算优先级问题
// 例如：
// 3 * MIN(10, 20)
//
// 宏展开后变成：
// 3 * 10 <= 20 ? 10 : 20
//
// 实际等价于：
// (3 * 10 <= 20) ? 10 : 20
//
// 所以结果不符合预期。
//
// 解决方法：
#define MIN1(A,B) (A <= B ? A : B)


// 问题2：参数没有加括号
// 例如：
// MIN1(10, 20 < 30 ? 20 : 30)
//
// 宏展开后可能因为参数表达式优先级导致结果不符合预期。
//
// 解决方法：
#define MIN2(A,B) ((A) <= (B) ? (A) : (B))


// 问题3：参数可能被多次计算
// 例如：
// MIN2(a++, 20 < 30 ? 20 : 30)
//
// 宏展开后：
// ((a++) <= (20 < 30 ? 20 : 30) ? (a++) : (20 < 30 ? 20 : 30))
//
// a++ 可能执行两次，导致结果不符合预期。
//
// 解决方法：使用 GNU C 扩展 typeof 和语句表达式，只计算一次参数。
#define MIN3(A,B) ({              \
    typeof(A) _min1 = (A);        \
    typeof(B) _min2 = (B);        \
    _min1 < _min2 ? _min1 : _min2;\
})


int main(void)
{
    int a = 10;

    printf("min = %d \n", 3 * MIN3(a++, 20 < 30 ? 20 : 30));
    printf("a = %d \n", a);

    return 0;
}

// 使用 MIN3 时：
// a++ 只会执行一次。
// 初始 a = 10
// _min1 = 10，然后 a 变成 11
// _min2 = 20
// MIN3 返回 10
// 3 * 10 = 30
//
// 输出结果：
// min = 30
// a = 11
```

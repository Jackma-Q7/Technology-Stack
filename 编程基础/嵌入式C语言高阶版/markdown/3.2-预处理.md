### 3.2.1 条件编译
 1、调试版本和release版本（调试信息的脱敏、性能的影响：code⼤⼩、运⾏效率）

```c
#include <stdio.h>
int password = 0x37847110;
int main(void)
{     
    printf("debug log：password is %x\n",password);
    return 0;
}
```

问：以上打印的debuglog，怎么样在不修改代码的情况下去掉？ 

代码可以改造成这样：  

```c
#include <stdio.h>

int password = 0x37847110;

int main(void)
{
#ifdef DEBUG
    printf("debug log：password is %x\n", password);
#else
    printf("release version \n");
#endif
return 0;
}
```

编译时⽤gcc-Dxx选项定义宏

```c
gcc -o bin 1.c -D DEBUG
./bin
#程序运⾏结果
log：password is 37847110
```

### 3.2.3 宏函数
#### 3.2.3.1 宏函数的定义
&emsp;&emsp;宏函数本质不是函数。展开规则依旧是纯粹⽂本替换，不会检测语法错误。正因如此，宏函数直接插⼊调⽤的地⽅，少了函数调⽤的消耗（出栈⼊栈等操作），所以是典型的⽤空间换性能的做法。 同样的，为了宏展开不会出错建议：整体和变量都加上()  

```c
#define 宏名(x) (x)
#define ADD(a, b) ((a)+(b))
#define RAD2DEG(x)((x)*57.295f)
#define F2C(x)(((x)-32)*5/9)
```
```c

                        a, b, MAX(a++, b++));

 }
```

```c
#参考linux下MAX的实现(3.18内核) 
#define MAX(x, y) ({                      
        typeof(x) _max1 = (x);            
        typeof(y) _max2 = (y);            
        (void) (&_max1 == &_max2);        
        _max1 > _max2 ? _max1 : _max2; })
```

###  3.2.4 系统预定义的宏 
**`__FUNCTION__`**：函数名  
**`__LINE__`**：调⽤所在⾏数  
**`__FILE__`**: 函数所在⽂件名

```c
#include <stdio.h>

#define LOG_INFO(x) \
    printf("%s %s:line:%d: %d\n", \
           __FILE__, \
           __FUNCTION__, \
           __LINE__, \
           (x))

int main(void)
{
    int a = 10;

    LOG_INFO(a);

    return 0;
}
#程序运⾏结果
1.c main:line:12：10
```

### 4.2.1 C与"继承"  
继承是使⽤已存在的类作为基础建⽴新的类的技术。新的类可以增加新的数据类型或者⽅法，也 可以使⽤⽗类的功能，但不能选择性的继承⽗类。通过继承可以很好的复⽤以前的代码，提⾼开发效 率。

可以想象成：

```plain
rect
 ├── s
 │    ├── width = 0   （未显式初始化时，聚合初始化里没写的成员会补 0）
 │    ├── height = 0
 │    ├── setWidth  -> 指向函数 setWidth
 │    └── setHeight -> 指向函数 setHeight
 └── getArea -> 指向函数 getArea
```

这里 `width` 和 `height` 没写初始化值，所以会被补成 0。

可以把整个过程画成这样：

```plain
main 开始
  ↓
创建 rect，并初始化函数指针
  ↓
rect.s.setWidth(&rect.s, 5)
  ↓
跳到 setWidth
  ↓
rect.s.width = 5
  ↓
返回 main
  ↓
rect.s.setHeight(&rect.s, 7)
  ↓
跳到 setHeight
  ↓
rect.s.height = 7
  ↓
返回 main
  ↓
rect.getArea(&rect.s)
  ↓
跳到 getArea
  ↓
返回 5 * 7 = 35
  ↓
返回 main
  ↓
printf 输出 Total area: 35
  ↓
return 0
  ↓
程序结束
```

## 6.2-修饰符-const

```c
C：只读，建议性，不具备强制性。`!` 常量。

`const` 意味着“只读”。

const int a = 100;

意思是：a 是变量，但是希望它的值尽量保持 100 不变，不建议修改。

但是在 C 语言里，const 不是绝对意义上的常量，它更像是告诉编译器：这个变量只读，不要直接修改它。

const int a;

int const a;

这两个写法作用一样，a 是一个常整型数，也就是 a 的值不建议被修改。

const int *a;

意思是：a 是一个指向常整型数的指针。

也就是说：

指针 a 可以修改，可以指向别的地方。

但是 a 指向的那个 int 值不可以通过 a 修改。

例如：

const int num1 = 10;
const int num2 = 20;

const int *a = &num1;

a = &num2;   // 可以，指针可以改
*a = 30;     // 不可以，不能通过 a 修改它指向的值

int * const a;

意思是：a 是一个指向整型数的常指针。

也就是说：

指针 a 自己不可以修改，不能再指向别的地方。

但是 a 指向的那个 int 值可以修改。

例如：

int num1 = 10;
int num2 = 20;

int * const a = &num1;

*a = 30;     // 可以，修改 num1 的值
a = &num2;   // 不可以，指针 a 不能改

int const * const a;

等价于：

const int * const a;

意思是：a 是一个指向常整型数的常指针。

也就是说：

指针 a 自己不能修改。

a 指向的那个 int 值也不能通过 a 修改。

例如：

int num1 = 10;
int num2 = 20;

const int * const a = &num1;

*a = 30;     // 不可以，不能修改指向的值
a = &num2;   // 不可以，指针本身也不能改

总结：

const int a;
int const a;

表示 a 是只读整型变量。

const int *a;

表示指针可以改，指向的值不能改。

int * const a;

表示指针不能改，指向的值可以改。

const int * const a;

表示指针不能改，指向的值也不能改。

记忆方法：

看 const 在 * 的哪边。

const 在 * 左边：限制的是指针指向的内容。

const 在 * 右边：限制的是指针本身。

例子：

const int *p;

const 在 * 左边，所以 *p 不能改，p 可以改。

int * const p;

const 在 * 右边，所以 p 不能改，*p 可以改。

const int * const p;

* 左边和右边都有 const，所以 p 不能改，*p 也不能改。

合理使用 const 可以让编译器帮助保护那些不希望被改变的数据，防止被无意修改，从而减少 bug。
```

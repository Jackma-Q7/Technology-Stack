###  2.4.1 gdb简介  
&emsp;&emsp;gdb是GNUProjectDebugger的简称，也是GNU(GNU'sNotUnix)开源项⽬中遵循GPL发⾏许可 证的freesoftware。掌握gdb调试技巧，在项⽬上遇到问题才会得⼼应⼿。gdb官⽅⽹站 (https://sourceware.org/gdb/)  

⼀般来说，GDB主要能够提供以下四个⽅⾯的帮助：  

1.是控制程序的执行流程（如启动、单步运行、继续执行等），让程序按你的节奏运行；

2.是通过设置断点在关键位置暂停程序，方便定位问题；

3.是查看和修改变量及内存数据，实时掌握程序内部状态；

4.是分析函数调用栈，尤其在程序崩溃时帮助追踪错误来源。

### 2.4.2 安装gdb
sudo apt-get update  

sudo apt-get install gdb  

# 查看 gdb 版本信息  

gdb --version  

# 启动 gdb 

gdb xx -q 

gdb -p 进程号 

gdb xx core  

### 2.4.3 gdb常⻅命令
1. [gdbxx]：启动xx可执⾏程序调试
2. [gdbxx-q]：启动xx可执⾏程序调试，并忽略gdb版本信息打印
3. [l ⾏号]：展⽰⾏号附近的代码
4. [r]：运⾏程序
5. [b⾏号/函数名]：设置断点
6. [info b]：查看断点
7. [dxx]：删除断点
8. [c]：继续执⾏
9. [n]：单步执⾏
10. [pxx]：打印变量的值
11. [set var xx=xx]：设置变量的值
12. [x 内存地址]：查看对应内存地址的值
13. [info r]：查看寄存器的值
14. [info thread]：查看信息信息
15. [thread 线程号]：切换运⾏上下⽂到对应线程
16. [disass]：展⽰当前汇编
